# Бенчмаркинг { #benchmarking }

GPUStack может запускать бенчмарки работающих экземпляров моделей. Воркеры выполняют их в специальном контейнерном образе; результаты и журналы сохраняются на воркере.

## Предварительные условия { #prerequisites }

- Экземпляр модели работает и исправен.

## Создать эталонный тест { #create-benchmark }

1. Перейдите на страницу `Benchmarks`.
2. Нажмите `Add Benchmark`.
3. Выберите экземпляр и заполните конфигурации.
4. Нажмите кнопку `Save`.

### Длины нагрузки ShareGPT { #sharegpt-workload-lengths }

Для встроенного набора ShareGPT можно задать минимальную и/или максимальную длину входа в токенах. GPUStack оставляет промпты первого хода, число токенов которых по токенизатору соответствует ограничениям. Длина выхода необязательна: если она задана, для каждого отобранного промпта запрашивается один и тот же максимум; иначе используется длина эталонного ответа из набора данных. Если ни один промпт не попадает в диапазон, запуск завершится ошибкой до отправки запросов бенчмарка.

## Просмотр результатов тестирования { #view-benchmark-results }

1. Перейдите на страницу `Benchmarks`.
2. Найдите тест, который хотите просмотреть.
3. Щелкните имя теста, чтобы просмотреть снимок результатов и конфигурации.

## Результаты тестирования экспорта { #export-benchmark-results }

1. Перейдите на страницу `Benchmarks`.
2. Найдите тест, который хотите экспортировать.
3. Выберите один или несколько тестов для экспорта.
4. Нажмите кнопку `Export`, чтобы загрузить результаты.

## Редактировать тест { #edit-benchmark }

1. Перейдите на страницу `Benchmarks`.
2. Найдите тест, который хотите редактировать.
3. Нажмите кнопку `Edit` в столбце `Operations`.
4. При необходимости измените имя и описание.
5. Нажмите кнопку `Save`.

## Удалить тест { #delete-benchmark }

1. Перейдите на страницу `Benchmarks`.
2. Найдите тест, который хотите удалить.
3. Нажмите кнопку `Delete` в столбце `Operations`.
4. Подтвердите удаление.

## Тесты на HTTPS-сервере с частным центром сертификации { #benchmarks-on-an-https-server-with-a-private-ca }

Контейнер бенчмарка передаёт сведения о ходе выполнения серверу GPUStack по URL сервера, поэтому при HTTPS он должен проверить сертификат сервера. Бенчмарк работает в отдельном образе и самостоятельно не импортирует центры сертификации (CA), поэтому воркер передаёт ему свой доверенный набор CA, включая частные CA, смонтированные в `/usr/local/share/ca-certificates/` (см. [Дополнительные доверенные CA](../installation/installation.md#additional-trusted-cas)). Если CA доступен на воркере, дополнительная настройка не нужна.

Если проверка всё же не проходит, это не влияет на сам бенчмарк: нагрузка направляется экземпляру модели по обычному HTTP. Однако до завершения запуска прогресс остаётся 0%, а причина записывается в журнал воркера. Для исправления импортируйте CA сервера на воркере.
