# Открытые ключи SSH службы графического процессора { #gpu-service-ssh-public-keys }

Открытые ключи SSH службы графического процессора позволяют управлять открытыми ключами SSH, используемыми для доступа к экземплярам службы графического процессора, обеспечивая безопасный доступ без пароля.

Вы назначаете эти ключи экземпляру в его конфигурации `SSH Access`; см. [Экземпляры службы графического процессора](gpuservice-instances.md).

## Просмотр открытых ключей SSH { #browse-ssh-public-keys }

Перейдите на страницу `GPU Service` > `SSH Public Keys`, чтобы просмотреть все зарегистрированные ключи.

![Снимок экрана: список открытых ключей SSH](../assets/gpuservice/ssh-public-keys/list.png)

Вы можете фильтровать открытые ключи SSH по отображаемому имени или имени — любое значение может отображаться в столбце `Name`. Сортировка порядков столбцов `Name` по отображаемой метке.

## Добавление открытого ключа SSH. { #adding-an-ssh-public-key }

На странице `SSH Public Keys` нажмите `Add SSH Public Key`, чтобы открыть форму создания.

![Снимок экрана: добавление формы открытого ключа SSH](../assets/gpuservice/ssh-public-keys/add.png)

Введите `Name`, затем вставьте свой ключ в поле `SSH Public Key`. Каждый ключ должен начинаться с `ssh-`, и вы можете зарегистрировать несколько ключей, вводя по одному в каждой строке. Нажмите `Save`, чтобы закончить.

!!! tip

    Чтобы распечатать свой открытый ключ, введите `cat ~/.ssh/id_rsa.pub` (RSA) или `cat ~/.ssh/id_ed25519.pub` (Ed25519).

## Редактирование открытого ключа SSH. { #editing-an-ssh-public-key }

Нажмите `Edit` на ключе, чтобы открыть его конфигурацию, обновить настройки, и нажмите `Save`.

![Скриншот: Редактировать форму открытого ключа SSH](../assets/gpuservice/ssh-public-keys/edit.png)

## Удаление открытого ключа SSH { #deleting-an-ssh-public-key }

Нажмите `Delete` на кнопке и подтвердите. После этого ключ удаляется из списка.

!!! note

    Если открытый ключ SSH уже используется экземпляром службы графического процессора, его удаление здесь не приведет к удалению его из этого экземпляра. Его содержимое уже синхронизировано с кластером на рабочей стороне, и ни одну запись нельзя удалить оттуда задним числом. Чтобы отозвать ключ из работающего экземпляра, откройте этот экземпляр, нажмите `Edit` и отмените выбор ключа в его конфигурации `SSH Access`.
