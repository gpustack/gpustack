# gpustack download-tools { #gpustack-download-tools }

Загрузка вспомогательных инструментов, включая gguf-parser и fastfetch.

```bash
gpustack download-tools [OPTIONS]
```

## Настройки { #configurations }

| <div style="width:180px">Флаг</div> | <div style="width:100px">По умолчанию</div> | Описание |
| ----------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------- |
| `--tools-download-base-url` значение | (пусто) | Базовый URL для загрузки вспомогательных инструментов. |
| `--save-archive` значение              | (пусто) | Путь для сохранения загруженных инструментов в tar-архиве. |
| `--load-archive` значение              | (пусто) | Путь к tar-архиву с инструментами для загрузки из архива вместо скачивания. |
| `--system` значение                    | По умолчанию — текущая ОС. | Операционная система, для которой загружаются инструменты. Варианты: `linux`, `windows`, `macos`. |
| `--arch` значение                      | По умолчанию — текущая архитектура. | Архитектура, для которой загружаются инструменты. Варианты: `amd64`, `arm64`. |
