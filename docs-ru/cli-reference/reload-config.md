# gpustack reload-config { #gpustack-reload-config }

Перезагрузка значений конфигурации, которые можно безопасно менять во время работы.

```bash
gpustack reload-config [OPTIONS]
```

## Настройки { #configurations }

| <div style="width:180px">Флаг</div> | <div style="width:100px">По умолчанию</div> | Описание |
| ----------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--set` значение                       | (пусто) | Задать одно разрешённое поле в формате `key=value` (ключи разделяются дефисами). Значения приводятся к типу поля: логические поля принимают `true/false`, `1/0`, `yes/no`, `y/n`, `on/off`; списки — строки с разделителями-запятыми; словари — строки JSON. Флаг `--set` можно указать несколько раз; последующие значения переопределяют предыдущие и значения из `--file`. |
| `--file` значение                      | (пусто) | Загрузить конфигурацию из YAML-файла. Применяются только разрешённые поля. Ключи нормализуются в snake_case. Значения из `--set` переопределяют значения из файла. |
| `--list`                            | `False`                                | Показать разрешённые поля и значения. Если этот флаг задан, остальные параметры игнорируются. |
| `--api-key` значение                   | (пусто) | Предоставить API-ключ для аутентификации на сервере от имени администратора. |
| `--server-port` значение               | `30080`                                | Целевой порт API-сервера GPUStack для применения или просмотра конфигурации во время работы. Если не указан, используется `GPUSTACK_API_PORT`, если эта переменная задана; иначе — `30080`. |
| `--worker-port` значение               | `10150`                                | Целевой порт воркера GPUStack для применения или просмотра конфигурации во время работы. Если не указан, используется `GPUSTACK_WORKER_PORT`, если эта переменная задана; иначе — `10150`. |
