# 貢献者の行動規範 { #contributor-code-of-conduct }

## 私たちの誓約 { #our-pledge }

私たちはメンバー、貢献者、リーダーとして、コミュニティへの参加を
誰にとってもハラスメントのない体験にすることを誓います。年齢、体型、
見える障害や見えない障害、民族、性的特徴、性自認やジェンダーの表現、
経験の程度、教育、社会経済的地位、
国籍、外見、人種、カースト、肌の色、宗教、
性的アイデンティティーや性的指向を問いません。

私たちは、開かれた、歓迎的で、多様性と包摂性のある、
健全なコミュニティに寄与する行動と交流を誓います。

## 私たちの基準 { #our-standards }

コミュニティに良い環境をもたらす行動には、
次のようなものがあります。

- 他者に共感し、親切に接すること。
- 異なる意見、視点、経験を尊重すること。
- 建設的なフィードバックを行い、快く受け入れること。
- 自分の過ちに責任を持ち、影響を受けた人に謝罪し、
  その経験から学ぶこと。
- 個人としての自分だけでなく、コミュニティ全体にとって
  最善となることを重視すること。

受け入れられない行動には、次のようなものがあります。

- 性的な言葉や画像の使用、およびあらゆる種類の
  性的な関心の押し付けや誘いかけ。
- 荒らし、侮辱的・中傷的な発言、個人的または政治的な攻撃。
- 公の場や私的な場でのハラスメント。
- 明示的な許可なく、住所やメールアドレスなど他者の個人情報を
  公開すること。
- その他、職業上の場面で不適切と合理的に判断される
  行為。

## 施行の責任 { #enforcement-responsibilities }

コミュニティのリーダーは、許容される行動の基準を明確にし、施行する責任を負います。
不適切、脅迫的、攻撃的、または有害と判断した行動に対して、
適切かつ公正な是正措置を
講じます。

コミュニティのリーダーは、この行動規範に沿わないコメント、コミット、
コード、Wiki の編集、Issue、その他の貢献を削除、編集、拒否する
権利と責任を持ちます。また、必要に応じて、
判断の理由を説明します。

## 適用範囲 { #scope }

この行動規範は、すべてのコミュニティの場、および個人が公の場で
コミュニティを公式に代表する場合に適用されます。
公式代表の例として、公式メールアドレスの使用、
公式ソーシャルメディアアカウントでの投稿、オンラインまたはオフラインの
イベントで任命された代表者として活動することがあります。

## 施行 { #enforcement }

虐待的、嫌がらせ、その他の受け入れられない行動は、
施行を担当するコミュニティのリーダーに、次のアドレスで報告できます。
<contact@gpustack.ai>.
すべての申し立てを迅速かつ公正に審査・調査します。

すべてのコミュニティリーダーは、事案を報告した人の
プライバシーと安全を尊重する義務があります。

## 施行のガイドライン { #enforcement-guidelines }

コミュニティのリーダーは、この行動規範に違反したと判断した行動に対して、
次のコミュニティへの影響に関するガイドラインに従い措置を決定します。

### 1. 是正 { #1-correction }

**コミュニティへの影響：** 不適切な言葉の使用、またはコミュニティで
非専門的・好ましくないと判断される行動。

**措置：** コミュニティリーダーが非公開の書面による警告を行い、
違反の内容と、その行動が不適切であった理由を
説明します。公の謝罪を求める場合があります。

### 2. 警告 { #2-warning }

**コミュニティへの影響：** 単独の事案または一連の行動による
違反。

**措置：** 行動が続いた場合の措置を明示した警告を行います。
一定期間、関係者との交流を禁じます。行動規範の施行担当者への
求められていない接触も対象です。
コミュニティ内の場に加え、ソーシャルメディアなどの外部チャンネルでの
交流も避けてください。この条件に違反すると、一時的または恒久的な
参加禁止につながる場合があります。

### 3. 一時的な参加禁止 { #3-temporary-ban }

**コミュニティへの影響：** 継続的な不適切行動など、
コミュニティ基準への重大な違反。

**措置：** 一定期間、コミュニティとのあらゆる交流や公の
コミュニケーションを禁止します。この期間中は、関係者との
公私を問わない交流を禁止します。行動規範の施行担当者への
求められていない接触も含まれます。
条件に違反すると、恒久的な参加禁止となる場合があります。

### 4. 恒久的な参加禁止 { #4-permanent-ban }

**コミュニティへの影響：** 継続的な不適切行動、個人へのハラスメント、
特定の集団への攻撃や中傷など、コミュニティ基準への
違反を繰り返す行動。

**措置：** コミュニティ内でのあらゆる公の交流への参加を
恒久的に禁止します。
