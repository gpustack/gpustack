# 動画 Playground { #video-playground }

動画 Playground では、GPUStack の動画生成 API を試し、パラメーターを調整し、生成された動画を再生できます。API 連携用のコード例も確認できます。

## 動画の生成 { #generate-video }

### プロンプト { #prompt }

プロンプトを入力して **送信** をクリックすると、非同期の動画生成が始まります。ページが追跡するのは最後に保存されたタスク 1 件です。プロンプトは再利用できるよう入力欄に残ります。状態確認エラーの後に再送信しても、先に送信したタスクは推論エンジンで続行されることがあります。

### 生成の進捗 { #generation-progress }

ページが表示されている間、Playground は現在のタスクの状態を 5 秒ごとに確認します。各確認のタイムアウトは 5 秒です。結果領域には待機中または生成中の状態が表示され、エンジンが 0 より大きい生成の進捗を返すとパーセントで表示されます。状態の確認に失敗するかタイムアウトすると、待機中または生成中の表示が消え、今回のポーリングが停止します。エラーは結果領域の下、プロンプト入力欄の上に表示され、再送信できるようになります。状態確認で HTTP 404 が返ると、このブラウザーの最新の記録も消去されます。その他のエラーでは記録が残り、再読み込みするかページに戻ると同じタスクを再確認できます。

### ページの切り替え { #switch-pages }

Playground は、このブラウザーにアカウントごとに最新の動画 ID と送信済みのパラメーターを保存します。再読み込み時にフォームを復元し、その ID の状態を確認します。ページを離れるかタブを非表示にすると確認が一時停止し、戻ると保存されたタスクを再確認します。

### 現在のタスク { #tasks }

結果領域に現在のタスクが表示されます。完了済みのタスクがある状態で再読み込みすると、動画のダウンロードが完了し、幅と高さを取得してからプレーヤーが表示されます。動画の取得可否は、タスクを作成した推論インスタンスとエンジンのタスク保持期間によって決まります。

### リクエストの停止 { #stop-request }

プロンプトのツールバーにある **生成をキャンセル** をクリックすると、すぐにキャンセル操作が実行されます。動画 ID を待っている間は、ブラウザーからの作成リクエストだけがキャンセルされます。推論エンジンがすでにリクエストを受け取っている場合、生成が続くことがあります。ID の取得後は、Playground がキャンセルリクエストを推論エンジンに転送します。キャンセルが成功すると、ブラウザーの記録が消去され、結果領域は空の状態に戻ります。ファイルの削除はエンジンが処理します。

ランダムプロンプトボタンの隣にある **動画記録を消去** では、確認後にこのブラウザー内の動画 ID、送信済みのパラメーター、プレビューだけを消去します。

## モデルの選択 { #select-model }

パラメーターパネルのドロップダウンから、利用可能なモデルを選択します。`video` カテゴリーのモデルのみが表示されます。モデルが表示されない場合は、実行中であることと、デプロイおよびルートのカテゴリーが正しいことを確認してください。

互換性のある SGLang Diffusion または vLLM-Omni のデプロイを使用してください。動画理解モデルは `llm` カテゴリーに属し、Chat Playground で使用します。

## パラメーター { #parameters }

| パラメーター | デフォルト | 説明 |
| --- | --- | --- |
| `長さ（秒）` | モデルの既定値、または `4` | 動画の長さのメタデータがある場合は、指定範囲内の整数を入力します。MiniMax H3 では 4–15 秒です。メタデータがない場合は `4`、`8`、`12` 秒から選択します。フレーム数の調整により、生成された動画の長さが指定値とわずかに異なる場合があります。 |
| `Resolution` | `832x480` またはモデルのプリセット | `幅x高さ` 形式の出力サイズ。プリセットを選択すると実際の寸法を送信します。 |
| `Seed` | ランダム | **ランダムシード** をオフにすると、固定のシード値を入力できます。 |
| `Reference Image` | （空） | 詳細設定のオプション入力。PNG/JPEG 画像をアップロードするか、HTTP(S) の画像 URL を入力します。 |

クリアボタンで参照画像または URL を削除できます。参照画像への対応は選択したモデルによって異なります。`video` カテゴリーを選択しても、テキストから動画を生成するモデルが自動的に画像入力へ対応するわけではありません。

タイルで比率を選び、ボタンで解像度を選択します。利用可能な場合は 480p、720p、1080p、4k を表示し、選択肢にカーソルを合わせると実際の幅と高さを表示します。モデルのメタデータによって寸法の追加や制限が可能です。これらは UI のプリセットであり、エンジンがすべての寸法を受け付ける保証ではありません。21:9 はなく、比率で `Custom` を選ぶと、スライダーまたは数値入力で幅と高さを調整できます。初期サイズはモデルのメタデータを優先し、ない場合はモデルの制限内で `832x480`（16:9）を使用します。

## モデルの機能 { #model-capabilities }

MiniMax H3 のモデルメタデータには、ロードされた重みで利用できるタスク、既定の解像度、4–15 秒の長さ範囲が含まれます。`t2va` が利用できる場合、Playground はそのタスクを既定で選択します。サーバーはモデルファイルとロードされた重みの分割から機能を識別します。Catalog と Hugging Face からの直接デプロイの両方に対応し、既存のデプロイにはバックグラウンド処理で機能メタデータが追加されます。

Playground から MiniMax H3 の非同期タスクを作成する場合、UI は `POST /v1/videos` を送信する前に、フォーム入力（`task`、`size`、`seconds`、参照メディア）を選択した推論先のネイティブパラメーターへ変換します。SGLang は `task`、`conditions`、`target` を使用し、vLLM-Omni は `extra_params` とエンジン固有の参照フィールド（`image_reference`、`video_reference`、`audio_reference`、`frame_indices`）を使用します。

Playground の `Duration (seconds)` 入力は整数秒を受け付けます。エンジンが対応している場合は、詳細パラメーターでネイティブの長さパラメーターにより小数秒を指定できます。

タスク一覧はデプロイ済みモデルの能力メタデータに従います。利用可能なタスクが 1 つの場合は自動選択され、選択欄は表示されません。複数ある場合は詳細設定で選択します。

- `t2va`：参照入力を非表示にし、リクエストとコード例から参照フィールドを除外します。
- `fl2va`：最初のフレーム、最後のフレーム、または両方の画像をアップロードします。
- `ref2va`：URL またはアップロードで参照画像または動画を 1 件指定します。複数の参照や独立した音声を組み合わせる場合は API を使用します。

タスクやモデルを変更すると参照入力は消去されます。1 ファイルあたり画像は PNG/JPEG で 1 MiB、動画は MP4/MOV で 2 MiB までです。

## コードの表示 { #view-code }

プロンプトとパラメーターを調整した後、`View Code` をクリックすると、同じ入力で API を呼び出す例を確認できます。`curl`、`Python`、`Node.js` のコード例を提供しています。

コード例は、非同期の動画タスクを作成し、状態をポーリングして、完成した動画をダウンロードします。エンドポイントについては[動画生成](../../integrations/inference-apis.md#video-generation)を参照してください。
