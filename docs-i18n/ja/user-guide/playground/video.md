# 動画 Playground { #video-playground }

動画 Playground では、GPUStack の動画生成 API を試し、パラメーターを調整し、生成された動画を再生できます。API 連携用のコード例も確認できます。

## 動画の生成 { #generate-video }

### プロンプト { #prompt }

プロンプトを入力するか、ランダムプロンプトボタンを使用し、`Submit` をクリックして動画を生成します。

### 生成の進捗 { #generation-progress }

タスクの実行中は、動画領域に読み込みアニメーションと生成中のメッセージが表示されます。ページは 5 秒ごとにタスクの状態を確認します。推論エンジンが 0 より大きい進捗を返した場合のみ、パーセントを表示します。途中の進捗を返さないエンジンもあります。

生成とダウンロードが完了すると、動画を再生できます。生成中の再生には対応していません。

### ページの切り替え { #switch-pages }

生成タスクを追跡している間は、別のページに移動してもフォームとタスクが保持されます。Video ページを離れた場合やブラウザータブがバックグラウンドになった場合、状態の確認は一時停止します。Video ページを前面に戻すと、同じタスクを直ちに確認し、ポーリングを再開します。

この状態は現在のブラウザーページ内でのみ保持されます。ページを再読み込みしたり閉じたりすると失われます。

### リクエストの停止 { #stop-request }

`Stop` をクリックすると、現在のブラウザーリクエストと状態の確認を停止し、読み込み状態を終了します。推論エンジンが受け付けた生成タスクは実行を継続する場合があります。このボタンはエンジンにタスクのキャンセル要求を送信しません。再度送信すると、新しいタスクが作成されます。

## モデルの選択 { #select-model }

Playground の右上にあるモデルのドロップダウンから、利用可能なモデルを選択します。`video` カテゴリーのモデルのみが表示されます。モデルが表示されない場合は、実行中であることと、デプロイおよびルートのカテゴリーが正しいことを確認してください。

互換性のある SGLang Diffusion または vLLM-Omni のデプロイを使用してください。動画理解モデルは `llm` カテゴリーに属し、Chat Playground で使用します。

## パラメーター { #parameters }

| パラメーター | デフォルト | 説明 |
| --- | --- | --- |
| `Duration` | `4` 秒 | 要求する動画の長さ。ページでは `4`、`8`、`12` 秒を選択できます。実際に受け付ける値はモデルとエンジンによって異なります。 |
| `Resolution` | `720x1280` | `幅x高さ` 形式の出力サイズ。選択肢と初期値はモデルのメタデータによって変わる場合があります。 |
| `Reference Image` | （空） | 詳細設定のオプション入力。PNG/JPEG 画像をアップロードするか、HTTP(S) の画像 URL を入力します。 |

クリアボタンで参照画像または URL を削除できます。参照画像への対応は選択したモデルによって異なります。`video` カテゴリーを選択しても、テキストから動画を生成するモデルが自動的に画像入力へ対応するわけではありません。

## コードの表示 { #view-code }

プロンプトとパラメーターを調整した後、`View Code` をクリックすると、同じ入力で API を呼び出す例を確認できます。`curl`、`Python`、`Node.js` のコード例を提供しています。

コード例は、非同期の動画タスクを作成し、状態をポーリングして、完成した動画をダウンロードします。エンドポイントについては[動画生成](../../integrations/inference-apis.md#video-generation)を参照してください。
