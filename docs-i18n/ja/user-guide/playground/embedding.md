# 埋め込み Playground { #embedding-playground }

埋め込み Playground では、テキストを埋め込みベクトルに変換するモデルの能力をテストできます。複数のテキスト入力を試し、埋め込みを可視化し、API 連携用のコード例を確認できます。

## テキストの追加 { #add-text }

2 件以上のテキストを追加し、`Submit` ボタンをクリックして埋め込みを生成します。

## テキストの一括入力 { #batch-input-text }

`Batch Input Mode` を有効にすると、複数行のテキストを改行ごとに個別のエントリーへ自動的に分割します。複数のテキストを一度に処理する場合に便利です。

## 可視化 { #visualization }

PCA（主成分分析）で次元を削減し、埋め込みの結果を 2 次元プロットに表示できます。結果は次の 2 つの形式で確認できます。

1. **グラフ** — PCA の結果を視覚的に表示します。
2. **JSON** — 生の埋め込みを JSON 形式で表示します。

グラフ上の点の距離は、対応するテキスト同士の類似度を表します。点が近いほど、類似度が高いことを示します。

![埋め込み](../../assets/playground/embedding.png)

## クリア { #clear }

`Clear` ボタンをクリックすると、テキスト入力をリセットし、出力を消去します。

## モデルの選択 { #select-model }

Playground UI の右上にあるモデルのドロップダウンをクリックして、GPUStack で利用可能なモデルを選択できます。

## コードの表示 { #view-code }

テキスト入力を試した後、`View Code` ボタンをクリックすると、同じ入力で API を呼び出す方法を確認できます。`curl`、`Python`、`Node.js` のコード例を提供しています。
