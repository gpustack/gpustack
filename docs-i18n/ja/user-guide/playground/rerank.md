# リランキング Playground { #rerank-playground }

リランキング Playground では、クエリーとの関連度に応じて複数のテキストを並べ替えるリランカーモデルをテストできます。さまざまな入力テキストを試し、パラメーターを調整し、API 連携用のコード例を確認できます。

## テキストの追加 { #add-text }

リランキングするドキュメントに複数のテキストを追加します。

## テキストの一括入力 { #batch-input-text }

`Batch Input Mode` を有効にすると、複数行のテキストを改行ごとに個別のエントリーへ分割します。複数のテキストを効率よく処理できます。

## クリア { #clear }

`Clear` ボタンをクリックすると、ドキュメントとクエリーの結果をリセットします。

## クエリー { #query }

クエリーを入力し、`Submit` ボタンをクリックすると、クエリーとの関連度に基づくテキストの順位付き一覧を取得できます。

![リランキング](../../assets/playground/reranker.png)

## モデルの選択 { #select-model }

Playground UI の右上にあるモデルのドロップダウンをクリックして、GPUStack で利用可能なリランカーモデルを選択します。

## パラメーターの調整 { #customize-parameters }

パラメーター欄の `Top N` で、取得する一致テキストの数を指定します。

## コードの表示 { #view-code }

入力テキストとクエリーを試した後、`View Code` ボタンをクリックすると、同じ入力で API を呼び出す方法を確認できます。`curl`、`Python`、`Node.js` のコード例を提供しています。
