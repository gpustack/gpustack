# サイト設定 { #site-settings }

プラットフォーム管理者は **アクセス制御 → サイト設定** で GPUStack デプロイのブランド情報をカスタマイズできます。設定はすべてのユーザーと組織で共有され、サーバーデータベースに保存されるため、再起動後も複数のレプリカ間でも維持されます。

## サイトのカスタマイズ { #customize-the-site }

1. プラットフォーム管理者としてサインインし、**サイト設定** を開きます。
2. サイト名とメインカラーを設定します。
3. 必要に応じてロゴ、コンパクトなサイドバーロゴ、ダークテーマ用画像、ファビコンをアップロードします。
4. 必要に応じてフッターの会社名とリンクを設定します。
5. **変更を保存** をクリックします。現在のブラウザーには直ちに適用され、他のブラウザーでは次回の再読み込み時に反映されます。

サイト名はブラウザーのタイトルとロゴの代替テキストに使用されます。カスタムロゴがない場合、ログインページにはカスタム名が表示されます。ダークテーマのロゴがない場合は対応するライトテーマの画像を使用します。画像をクリアすると内蔵リソースに戻り、**デフォルトに戻す** を選ぶとメインカラーが初期値に戻ります。フッター項目が空の場合は GPUStack のデフォルト値を使用します。

画像は PNG、JPEG、WebP のいずれかで、各 512 KiB 以下にしてください。画像はデータベースに保存されます。外部画像 URL と SVG のアップロードには対応していません。フッターリンクには HTTP(S) URL または `/about` などの同一オリジンのパスを指定できます。

ブランド情報はサインイン前も公開されます。機密情報を入力しないでください。

公開読み取りには ETag が含まれ、キャッシュの再検証が必要です。一致する `If-None-Match` リクエストには本文のない `304 Not Modified` を返し、変更されていない画像の再ダウンロードを防ぎます。別のサーバーレプリカでの変更を直ちに反映するため、読み取りごとにデータベースを確認します。

## API { #api }

| メソッド | エンドポイント | アクセス |
| --- | --- | --- |
| GET | `/v2/site-settings/public` | 公開ブランド項目のみ。認証不要 |
| GET | `/v2/site-settings` | プラットフォーム管理者 |
| PUT | `/v2/site-settings` | 管理スコープを持つプラットフォーム管理者 |

`PUT` は設定全体を置き換えます。`site_name`（1～128 文字）と `primary_color`（`#007BFF` などの 6 桁の 16 進数カラー）は必須です。任意項目は `logo`、`logo_dark`、`mini_logo`、`mini_logo_dark`、`favicon`、`footer_name`（最大 128 文字）、`footer_url`（最大 2048 文字）です。省略した任意項目はクリアされます。画像には base64 データ URL を使用します。レスポンスの `updated_at` は最初の内容変更までは null です。不明な入力フィールドは拒否されます。

## デプロイの互換性 { #deployment-compatibility }

編集を有効にするには、対応するサーバーと UI のバージョンを一緒にデプロイしてください。サーバーの Alembic アップグレードは v2.3.1 マイグレーションバンドルで `site_settings` テーブルを作成します。最初の保存前は、レコードを作成せずに GPUStack のデフォルト値を返します。ダウングレードするとテーブルと保存済みのブランド情報が削除されます。

古いサーバーを使用する場合や、5 秒以内に公開設定を読み取れない場合、UI は GPUStack のデフォルト値で起動します。管理者用の読み取りに失敗すると編集が無効になり、再試行できます。

ブランドプラグインを含むビルドでは、プラグインの初期化と編集画面が維持されます。内蔵のサイト設定ページは、ブランドプラグインを含まないビルドで利用できます。
