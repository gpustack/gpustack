# NVIDIA A100 GPU 上での Qwen3-14B のスループット最適化 { #optimizing-qwen3-14b-throughput-on-nvidia-a100-gpus }


## 結論 { #conclusion }

![qwen3-14b-a100](../../assets/performance-lab/qwen3-14b-a100.png)

A100 GPU 上で Qwen3-14B のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    trtllm-serve Qwen/Qwen3-14B --max_seq_len=40960 --enable_chunked_prefill
    ```

最適化前後のベンチマーク結果の比較：

| ベンチマークケース | 基準設定（最適化なしの vLLM） | 最適化後 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | 合計 TPS: 3922.41<br>平均 TPOT(ms): 114.34 | 合計 TPS: 5770.24 <span style="background-color:lightgreen;">(+47.1%)</span><br>平均 TPOT(ms): 260.46 |
| **短いプロンプト** | 合計 TPS: 4916.63<br>平均 TPOT(ms): 233.35 | 合計 TPS: 8762.17 <span style="background-color:lightgreen;">(+78.2%)</span><br>平均 TPOT(ms): 715.19 |
| **中程度のプロンプト** | 合計 TPS: 5967.13<br>平均 TPOT(ms): 301.73 | 合計 TPS: 7474.00 <span style="background-color:lightgreen;">(+25.3%)</span><br>平均 TPOT(ms): 313.69 |
| **長いプロンプト** | 合計 TPS: 5153.42<br>平均 TPOT(ms): 254.61 | 合計 TPS: 6418.65 <span style="background-color:lightgreen;">(+24.6%)</span><br>平均 TPOT(ms): 196.10 |
| **非常に長いプロンプト** | 合計 TPS: 4430.14<br>平均 TPOT(ms): 445.58 | 合計 TPS: 4413.82 <span style="background-color:#fbcaca;">(-0.4%)</span><br>平均 TPOT(ms): 493.18 |


!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph、Torch Compile など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。


## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

Qwen3-14B

### ハードウェア { #hardware }

単一の NVIDIA A100 SXM GPU。

### エンジンのバージョン { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.5.post1
- TensorRT-LLM: v1.2.0rc1

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-14B --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-14B --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
