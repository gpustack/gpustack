# NVIDIA A100 GPU 上での GLM-4.5-Air のスループット最適化 { #optimizing-glm-45-air-throughput-on-nvidia-a100-gpus }


## 結論 { #conclusion }

![glm-4.5-air-a100](../../assets/performance-lab/glm-4.5-air-a100.png)

A100 GPU 上で GLM-4.5-Air のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    python3 -m sglang.launch_server --model-path zai-org/GLM-4.5-Air \
    --tp-size 4 --ep-size 4 --tool-call-parser glm --reasoning-parser glm45
    ```

最適化前後のベンチマーク結果の比較：

| ベンチマークケース | 基準設定（最適化なしの vLLM） | 最適化後（GPU 数を同数に換算） |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | 合計 TPS: 3903.44<br>平均 TPOT(ms): 104.59 | 合計 TPS: 6245.77 <span style="background-color:lightgreen;">(+60.0%)</span><br>平均 TPOT(ms): 309.31 |
| **短いプロンプト** | 合計 TPS: 6271.24<br>平均 TPOT(ms): 153.00 | 合計 TPS: 13012.20  <span style="background-color:lightgreen;">(+107.5%)</span><br>平均 TPOT(ms): 1246.57 |
| **中程度のプロンプト** | 合計 TPS: 8643.75<br>平均 TPOT(ms): 204.31 | 合計 TPS: 10956.49  <span style="background-color:lightgreen;">(+26.8%)</span><br>平均 TPOT(ms): 165.34 |
| **長いプロンプト** | 合計 TPS: 6975.10<br>平均 TPOT(ms): 267.38 | 合計 TPS: 9100.71 <span style="background-color:lightgreen;">(+30.5%)</span><br>平均 TPOT(ms): 124.68 |
| **非常に長いプロンプト** | 合計 TPS: 6435.97<br>平均 TPOT(ms): 305.47 | 合計 TPS: 7945.66 <span style="background-color:lightgreen;">(+23.5%)</span><br>平均 TPOT(ms): 276.41 |


!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。

## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

zai-org/GLM-4.5-Air

### ハードウェア { #hardware }

単一ノードに 4 × NVIDIA A100 SXM 80GB GPU。

### エンジンのバージョン { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.4.post2
- TensorRT-LLM: v1.2.0rc1

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model zai-org/GLM-4.5-Air --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model zai-org/GLM-4.5-Air --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
