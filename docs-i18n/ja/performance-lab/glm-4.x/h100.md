# NVIDIA H100 GPU 上での GLM-4.x のスループット最適化 { #optimizing-glm-4x-throughput-on-nvidia-h100-gpus }

## 結論 { #conclusion }

H100 GPU 上で GLM-4.x (4.5, 4.6、4.7) のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    python3 -m sglang.launch_server --model zai-org/GLM-4.6-FP8 --tp-size 8 --ep-size 8 --tool-call-parser glm --reasoning-parser glm45
    ```

!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。
    4. 量子化は精度に影響する場合がありますが、多くのモデルでは FP8 量子化による精度低下は 1% 未満です。詳細は[評価結果](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark)を参照してください。そのため、高スループットでのモデル提供には FP8 量子化を強く推奨します。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。

## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

zai-org/GLM-4.6

### ハードウェア { #hardware }

単一ノードに 8 × NVIDIA H100 SXM GPU。

### エンジンのバージョン { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.3
- TensorRT-LLM: v1.0.0

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model zai-org/GLM-4.6 --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model zai-org/GLM-4.6 --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```

## 実験結果 { #experiment-results }

元の BF16 精度モデルは、メモリ制約のため NVIDIA H100 GPU を搭載した単一サーバーでは提供できません。このため、FP8 量子化モデルの提供に焦点を当てています。
