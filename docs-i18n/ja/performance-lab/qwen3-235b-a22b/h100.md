# NVIDIA H100 GPU 上での Qwen3-235B-A22B のスループット最適化 { #optimizing-qwen3-235b-a22b-throughput-on-nvidia-h100-gpus }

## 結論 { #conclusion }

![qwen3-235b-a22b-h100](../../assets/performance-lab/qwen3-235b-a22b-h100.png)

H100 GPU 上で Qwen3-235B-A22B-Instruct-2507 のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    vllm serve Qwen/Qwen3-235B-A22B-Instruct-2507-FP8 -tp 4 --max-num-batched-tokens 16384
    ```

最適化前後のベンチマーク結果の比較：

| ベンチマークケース | 基準設定（最適化なしの vLLM） | 最適化後 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | 合計 TPS: 8424.86<br>平均 TPOT(ms): 147.56 | 合計 TPS: 7787.17x2 <span style="background-color:lightgreen;">(+84.9%)</span><br>平均 TPOT(ms): 186.26 |
| **短いプロンプト** | 合計 TPS: 14668.27<br>平均 TPOT(ms): 212.98 | 合計 TPS: 21211.83x2 <span style="background-color:lightgreen;">(+189.2%)</span><br>平均 TPOT(ms): 125.18 |
| **中程度のプロンプト** | 合計 TPS: 23858.69<br>平均 TPOT(ms): 101.08 | 合計 TPS: 18950.04x2 <span style="background-color:lightgreen;">(+58.9%)</span><br>平均 TPOT(ms): 125.93 |
| **長いプロンプト** | 合計 TPS: 21113.53<br>平均 TPOT(ms): 68.94 | 合計 TPS: 16478.79x2 <span style="background-color:lightgreen;">(+56.1%)</span><br>平均 TPOT(ms): 89.52 |
| **非常に長いプロンプト** | 合計 TPS: 22657.51<br>平均 TPOT(ms): 132.10 | 合計 TPS: 15366.32x2 <span style="background-color:lightgreen;">(+35.6%)</span><br>平均 TPOT(ms): 194.60 |


!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph、Torch Compile など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。
    4. 量子化は精度に影響する場合がありますが、多くのモデルでは FP8 量子化による精度低下は 1% 未満です。詳細は[評価結果](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark)を参照してください。そのため、高スループットでのモデル提供には FP8 量子化を強く推奨します。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。

## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

Qwen3-235B-A22B-Instruct-2507

### ハードウェア { #hardware }

単一ノードに 8 × NVIDIA H100 SXM GPU。

### エンジンのバージョン { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.5.post1

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
