# NVIDIA H100 GPU 上での GPT-OSS-120B のスループット最適化 { #optimizing-gpt-oss-120b-throughput-on-nvidia-h100-gpus }

## 結論 { #conclusion }

![gpt-oss-120b-h100](../../assets/performance-lab/gpt-oss-120b-h100.png)

H100 GPU 上で GPT-OSS-120B のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    vllm serve openai/gpt-oss-120b --async-scheduling -tp 2
    ```

最適化前後のベンチマーク結果の比較：

| ベンチマークケース | 基準設定（最適化なしの vLLM） | 最適化後 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | 合計 TPS: 6095.37<br>平均 TPOT(ms): 54.10 | 合計 TPS: 16042.19 <span style="background-color:lightgreen;">(+31.6%/GPU)</span><br>平均 TPOT(ms): 86.54 |
| **短いプロンプト** | 合計 TPS: 17059.15<br>平均 TPOT(ms): 304.80 | 合計 TPS: 31517.47 <span style="background-color:#fbcaca;">(-7.6%/GPU)</span><br>平均 TPOT(ms): 183.05 |
| **中程度のプロンプト** | 合計 TPS: 14385.69<br>平均 TPOT(ms): 41.35 | 合計 TPS: 34083.02 <span style="background-color:lightgreen;">(+18.5%/GPU)</span><br>平均 TPOT(ms): 139.32 |
| **長いプロンプト** | 合計 TPS: 14247.47<br>平均 TPOT(ms): 31.70 | 合計 TPS: 34491.13 <span style="background-color:lightgreen;">(+21.1%/GPU)</span><br>平均 TPOT(ms): 164.73 |
| **非常に長いプロンプト** | 合計 TPS: 16136.57<br>平均 TPOT(ms): 23.99 | 合計 TPS: 32471.01 <span style="background-color:lightgreen;">(+0.6%/GPU)</span><br>平均 TPOT(ms): 220.32 |


!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph、Torch Compile など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。

## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

GPT-OSS-120B

### ハードウェア { #hardware }

単一ノードに 2 × NVIDIA H100 SXM GPU。

### エンジンのバージョン { #engine-version }

- vLLM: v0.10.2
- SGLang: v0.5.3rc0
- TensorRT-LLM: v1.0.0

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model openai/gpt-oss-120b --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model openai/gpt-oss-120b --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
