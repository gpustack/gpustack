# gpustack reload-config { #gpustack-reload-config }

実行時に安全に変更できる構成値を再読み込みします。

```bash
gpustack reload-config [OPTIONS]
```

## 構成 { #configurations }

| <div style="width:180px">フラグ</div> | <div style="width:100px">既定値</div> | 説明 |
| ----------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--set` 値 | （空） | 許可リスト内の 1 つのフィールドを `key=value` で設定します（キーはハイフン区切り）。値はフィールドの型に変換されます。真偽値には `true/false`、`1/0`、`yes/no`、`y/n`、`on/off`、リストにはカンマ区切りの文字列、辞書には JSON 文字列を指定します。`--set` は複数指定でき、後の指定が前の指定と `--file` の値を上書きします。 |
| `--file` 値 | （空） | YAML ファイルから構成を読み込みます。許可リスト内のフィールドのみ適用されます。キーは snake_case に正規化されます。`--set` で指定した値はファイルの値を上書きします。 |
| `--list` | `False` | 許可リスト内のフィールドと値を表示します。指定すると、その他のオプションは無視されます。 |
| `--api-key` 値 | （空） | 管理者ユーザーとして Server 側の認証を行うための API キーを指定します。 |
| `--server-port` 値 | `30080` | 実行時構成の適用または一覧表示の対象となる GPUStack API Server のポート。省略した場合は `GPUSTACK_API_PORT` の設定値を使用し、未設定なら `30080` を使用します。 |
| `--worker-port` 値 | `10150` | 実行時構成の適用または一覧表示の対象となる GPUStack Worker のポート。省略した場合は `GPUSTACK_WORKER_PORT` の設定値を使用し、未設定なら `10150` を使用します。 |
