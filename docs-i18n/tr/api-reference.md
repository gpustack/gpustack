# API Referansı { #api-reference }

GPUStack yerleşik bir Swagger kullanıcı arayüzü sağlar. API'leri görüntülemek ve bunlarla etkileşimde bulunmak için tarayıcınızda `<gpustack-server-url>/docs` seçeneğine giderek buna erişebilirsiniz.
