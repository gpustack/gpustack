# ASCEND 910B NPU üzerinde Qwen3-8B işlem hacmi optimizasyonu { #optimizing-qwen3-8b-throughput-on-ascend-910b-npus }

## Sonuç { #conclusion }

![qwen3-8b-910b](../../assets/performance-lab/qwen3-8b-910b.png)

ASCEND 910B NPU üzerinde Qwen3-8B işlem hacmini optimize etmek için önerilen yapılandırma:

???+ tip "Model sunum komutu"
    ```bash
    # This is a simplified vLLM-like command. GPUStack maps arguments to the
    # corresponding MindIE JSON configuration and runs with mindieservice_daemon.
    mindie serve vllm-ascend/Qwen3-8B-W8A8 --enable-prefix-caching
    ```

Optimizasyon öncesi ve sonrası benchmark sonuçlarının karşılaştırması:

| Benchmark senaryosu | temel yapılandırma (optimizasyonsuz vLLM) | Optimize edilmiş |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | Toplam TPS: 3143.94<br>Ortalama TPOT(ms): 27.61 | Toplam TPS: 6256.39 <span style="background-color:lightgreen;">(+99.0%)</span><br>Ortalama TPOT(ms): 796.13 |
| **Kısa istem** | Toplam TPS: 5834.79<br>Ortalama TPOT(ms): 125.55 | Toplam TPS: 16611.86 <span style="background-color:lightgreen;">(+184.7%)</span><br>Ortalama TPOT(ms): 1131.26 |
| **Orta uzunlukta istem** | Toplam TPS: 9589.00<br>Ortalama TPOT(ms): 140.39 | Toplam TPS: 14484.86 <span style="background-color:lightgreen;">(+51.1%)</span><br>Ortalama TPOT(ms): 122.59 |
| **Uzun istem** | Toplam TPS: 7677.41<br>Ortalama TPOT(ms): 99.26 | Toplam TPS: 11159.01 <span style="background-color:lightgreen;">(+45.4%)</span><br>Ortalama TPOT(ms): 97.74 |
| **Çok uzun istem** | Toplam TPS: 2890.64<br>Ortalama TPOT(ms): 344.18 | Toplam TPS: 7835.01 <span style="background-color:lightgreen;">(+171.1%)</span><br>Ortalama TPOT(ms): 169.70 |


!!! note
    1. Benchmark testlerimiz olası tüm optimizasyon birleşimlerini kapsamaz. Örneğin, varsayılan yapılandırmasında en iyi performansı gösteren çıkarım motorunu sonraki ayarlamalar için başlangıç noktası olarak seçeriz. Bu eleme yaklaşımı yerel bir optimum verir; bu, genel optimum olmayabilir.
    2. En büyük toplu iş boyutu, zamanlama yapılandırması, genişletilmiş KV önbelleği, CUDA graph, Torch Compile gibi belirli kullanım senaryolarına bağlı başka optimizasyonlar da vardır. Bu belgedeki sonuçlar, daha hedefli optimizasyonlar için başlangıç noktası olabilir.
    3. Testler belirli donanım ve yazılım yapılandırmalarında yürütülmüştür. Çıkarım motorlarındaki gelişmeler sonuçları değiştirebilir.

Eksik noktalar veya yeni değişiklikleri yansıtacak güncellemeler varsa [bize bildirin](https://github.com/gpustack/gpustack/issues/new/choose).

## Optimizasyon hedefi { #optimization-objective }

Yüksek eş zamanlı isteklerde yüksek işlem hacmi sağlar.

## Deney kurulumu { #experimental-setup }

### Model { #model }

Qwen/Qwen3-30B-A3B

### Donanım { #hardware }

Tek Ascend 910B NPU.

### Motor sürümü { #engine-version }

- vLLM-Ascend: v0.9.1
- MindIE: 2.1RC1

### Benchmark veri kümesi { #benchmark-dataset }

1. ShareGPT
2. Farklı dizi uzunluklarına sahip rastgele veri kümesi:
    - Çok uzun istem: 32000 giriş token'ı, 100 çıkış token'ı
    - Uzun istem: 4000 giriş token'ı, 200 çıkış token'ı
    - Orta uzunlukta istem: 2000 giriş token'ı, 100 çıkış token'ı
    - Kısa istem: 128 giriş token'ı, 4 çıkış token'ı

### Benchmark betiği { #benchmark-script }

Model performansını ölçmek için **vLLM bench CLI** aracını kullanıyoruz. Benchmark şu komutla çalıştırılır:

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-8B --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-8B --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
