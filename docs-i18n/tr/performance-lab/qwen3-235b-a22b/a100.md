# NVIDIA A100 GPU üzerinde Qwen3-235B-A22B işlem hacmi optimizasyonu { #optimizing-qwen3-235b-a22b-throughput-on-nvidia-a100-gpus }


## Sonuç { #conclusion }

![qwen3-235b-a22b-a100](../../assets/performance-lab/qwen3-235b-a22b-a100.png)

A100 GPU üzerinde Qwen3-235B-A22B-Instruct-2507 işlem hacmini optimize etmek için önerilen yapılandırma:

???+ tip "Model sunum komutu"
    ```bash
    vllm serve Qwen/Qwen3-235B-A22B-Instruct-2507-FP8 -tp 4
    ```

Optimizasyon öncesi ve sonrası benchmark sonuçlarının karşılaştırması:

| Benchmark senaryosu | temel yapılandırma (optimizasyonsuz vLLM) | Optimize edilmiş |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | Toplam TPS: 3792.50<br>Ortalama TPOT(ms): 123.36 | Toplam TPS: 3019.19x2 <span style="background-color:lightgreen;">(+59.2%)</span><br>Ortalama TPOT(ms): 150.72 |
| **Kısa istem** | Toplam TPS: 7449.43<br>Ortalama TPOT(ms): 155.16 | Toplam TPS: 4961.66x2 <span style="background-color:lightgreen;">(+33.2%)</span><br>Ortalama TPOT(ms): 265.87 |
| **Orta uzunlukta istem** | Toplam TPS: 9342.67<br>Ortalama TPOT(ms): 190.79 | Toplam TPS: 5333.91x2 <span style="background-color:lightgreen;">(+14.2%)</span><br>Ortalama TPOT(ms): 342.39 |
| **Uzun istem** | Toplam TPS: 8170.72<br>Ortalama TPOT(ms): 205.64 | Toplam TPS: 4633.41x2 <span style="background-color:lightgreen;">(+13.4%)</span><br>Ortalama TPOT(ms): 347.13 |
| **Çok uzun istem** | Toplam TPS: 6657.49<br>Ortalama TPOT(ms): 298.86 | Toplam TPS: 4132.51x2 <span style="background-color:lightgreen;">(+24.1%)</span><br>Ortalama TPOT(ms): 481.71 |


!!! note
    1. Benchmark testlerimiz olası tüm optimizasyon birleşimlerini kapsamaz. Örneğin, varsayılan yapılandırmasında en iyi performansı gösteren çıkarım motorunu sonraki ayarlamalar için başlangıç noktası olarak seçeriz. Bu eleme yaklaşımı yerel bir optimum verir; bu, genel optimum olmayabilir.
    2. En büyük toplu iş boyutu, zamanlama yapılandırması, genişletilmiş KV önbelleği, CUDA graph, Torch Compile gibi belirli kullanım senaryolarına bağlı başka optimizasyonlar da vardır. Bu belgedeki sonuçlar, daha hedefli optimizasyonlar için başlangıç noktası olabilir.
    3. Testler belirli donanım ve yazılım yapılandırmalarında yürütülmüştür. Çıkarım motorlarındaki gelişmeler sonuçları değiştirebilir.
    4. Nicemleme doğruluğu etkileyebilir; ancak FP8 nicemleme çoğu modelde %1'den az doğruluk kaybı sağlayabilir. Ayrıntılar için [değerlendirme sonuçlarına](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark) bakın. Bu nedenle yüksek işlem hacimli sunum senaryolarında FP8 nicemleme önemle önerilir.

Eksik noktalar veya yeni değişiklikleri yansıtacak güncellemeler varsa [bize bildirin](https://github.com/gpustack/gpustack/issues/new/choose).


## Optimizasyon hedefi { #optimization-objective }

Yüksek eş zamanlı isteklerde yüksek işlem hacmi sağlar.

## Deney kurulumu { #experimental-setup }

### Model { #model }

Qwen3-235B-A22B-Instruct-2507

### Donanım { #hardware }

Tek düğümde 8 × NVIDIA A100 SXM 80GB GPU.

### Motor sürümü { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.5.post1

### Benchmark veri kümesi { #benchmark-dataset }

1. ShareGPT
2. Farklı dizi uzunluklarına sahip rastgele veri kümesi:
    - Çok uzun istem: 32000 giriş token'ı, 100 çıkış token'ı
    - Uzun istem: 4000 giriş token'ı, 200 çıkış token'ı
    - Orta uzunlukta istem: 2000 giriş token'ı, 100 çıkış token'ı
    - Kısa istem: 128 giriş token'ı, 4 çıkış token'ı

### Benchmark betiği { #benchmark-script }

Model performansını ölçmek için **vLLM bench CLI** aracını kullanıyoruz. Benchmark şu komutla çalıştırılır:

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
