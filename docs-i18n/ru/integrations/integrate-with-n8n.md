# Интеграция с n8n { #integrating-with-n8n }

[n8n](https://n8n.io/) — это расширяемый инструмент автоматизации рабочих процессов, распространяемый по модели fair-code. Он позволяет подключать любое приложение к API для управления и автоматизации задач. Благодаря передовым узлам искусственного интеллекта вы можете легко интегрировать большие языковые модели в свои автоматизированные рабочие процессы.

## Развертывание модели { #deploy-the-model }

Чтобы завершить развертывание модели, обратитесь к разделу **[Развертывание модели](../user-guide/model-deployment-management.md#deploy-model)** в документации GPUStack.

## Информация о доступе к API { #api-access-info }

1. Войдите в веб-интерфейс GPUStack.
2. Перейдите на страницу **Маршруты**.
3. В меню справа от целевой модели выберите **Информация о доступе к API**.

![](../assets/integrations/n8n-01.png)
![](../assets/integrations/n8n-02.png)

Запишите следующую информацию (если ключ API еще не создан, следуйте инструкциям на странице, чтобы его создать):

* **URL-адрес доступа**
* **Ключ API**

## Установите n8n { #install-n8n }

Следуйте официальной документации n8n, чтобы выполнить самостоятельную установку, или используйте облачный сервис n8n напрямую: [https://docs.n8n.io/hosting/](https://docs.n8n.io/hosting/)
