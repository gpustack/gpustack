# Управление файлами модели { #model-file-management }

GPUStack позволяет администраторам загружать файлы моделей и управлять ими.

## Добавить файл модели { #add-model-file }

GPUStack в настоящее время поддерживает модели из [Hugging Face](https://huggingface.co), [ModelScope](https://modelscope.cn) и локальных путей. Чтобы добавить файлы модели, перейдите на страницу `Model Files`.

### Добавьте модель Hugging Face. { #add-a-hugging-face-model }

1. Нажмите кнопку `Add Model File` и выберите `Hugging Face` из раскрывающегося списка.
2. Используйте панель поиска в левом верхнем углу, чтобы найти модель по названию, например, `Qwen/Qwen3-0.6B`.
3. _(Необязательно)_ Для моделей GGUF выберите желаемый формат квантования из `Available Files`.
4. Выберите целевого воркера для загрузки файла модели.
5. _(Необязательно)_ Укажите `Local Directory`, чтобы загрузить модель по пользовательскому пути вместо каталога кэша GPUStack.
6. Нажмите кнопку `Save`.

### Добавьте модель ModelScope. { #add-a-modelscope-model }

1. Нажмите кнопку `Add Model File` и выберите `ModelScope` из раскрывающегося списка.
2. Используйте панель поиска в левом верхнем углу, чтобы найти модель по названию, например, `Qwen/Qwen3-0.6B`.
3. _(Необязательно)_ Для моделей GGUF выберите желаемый формат квантования из `Available Files`.
4. Выберите целевого воркера для загрузки файла модели.
5. _(Необязательно)_ Укажите `Local Directory`, чтобы загрузить модель по пользовательскому пути вместо каталога кэша GPUStack.
6. Нажмите кнопку `Save`.

### Добавьте модель локального пути. { #add-a-local-path-model }

Вы можете добавлять модели по локальному пути. Путь может представлять собой каталог (например, папку модели Hugging Face) или файл (например, модель GGUF), расположенный на воркере.

1. Нажмите кнопку `Add Model File` и выберите `Local Path` из раскрывающегося списка.
2. Введите `Model Path`.
3. Выберите целевого воркера.
4. Нажмите кнопку `Save`.

## Повторить загрузку { #retry-download }

Если загрузка файла модели не удалась или зависла на очень низкой скорости загрузки, вы можете повторить попытку:

1. Перейдите на страницу `Model Files`.
2. Найдите файл модели.
3. Нажмите кнопку с многоточием в столбце `Operations` и выберите `Retry Download`.
4. GPUStack попытается снова загрузить файл модели из указанного источника.

## Развертывание модели { #deploy-model }

Модели можно развертывать из файлов моделей. Поскольку модель хранится в конкретном воркере, GPUStack добавит селектор воркера с помощью клавиши `worker-name`, чтобы обеспечить правильное планирование.

!!! tip

    Если вы хотите, чтобы модель выполняла аварийное переключение между узлами, убедитесь, что все узлы в кластере могут получить доступ к файлам модели по одному и тому же пути, и вручную удалите метку `worker-name` из селектора воркеров.

1. Перейдите на страницу `Model Files`.
2. Найдите файл модели, который хотите развернуть.
3. Нажмите кнопку `Deploy` в столбце `Operations`.
4. Просмотрите или измените `Name`, `Backend`, `Backend Version`, `Replicas` и другие параметры развертывания.
5. Нажмите кнопку `Save`.

## Удалить файл модели. { #delete-model-file }

1. Перейдите на страницу `Model Files`.
2. Найдите файл модели, который хотите удалить.
3. Нажмите кнопку с многоточием в столбце `Operations` и выберите `Delete`.
4. _(Необязательно)_ Отметьте опцию `Also delete the file from disk`.
5. Нажмите кнопку `Delete` для подтверждения.
