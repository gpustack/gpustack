# Управление облачными учетными данными { #cloud-credential-management }

GPUStack поддерживает управление облачными учетными данными, обеспечивая безопасные соединения с внешними поставщиками облачных услуг. Учетные данные облака содержат информацию о поставщике, ключи и параметры, необходимые для доступа к API.

## Поддерживаемые провайдеры { #supported-providers }

Поддерживаются `DigitalOcean` и `SHUIHUA FUTURE`.

## Создание облачных учетных данных { #create-cloud-credential }

1. Перейдите на страницу `Cloud Credentials`.
2. Нажмите раскрывающийся список `Add Cloud Credential` и выберите поставщика.
3. Заполните следующую информацию:

   - `Name`: уникальное имя набора учётных данных.
   - Секрет провайдера, который является единственным полем учетных данных, которое необходимо каждому:
     - `DigitalOcean` — `Access Token`, токен API, сгенерированный на странице `Applications & API` DigitalOcean. Область токена должна быть `Full Access`.
     - `SHUIHUA FUTURE` — `API Key`, созданный на консоли [Shuihua](https://hub.do.top/cn/signin) и имеющий префикс `amp_live_`.
   - `Description`: дополнительная информация об облачных учетных данных.

4. Нажмите кнопку `Save`.

## Обновить облачные учетные данные { #update-cloud-credential }

1. Перейдите на страницу `Cloud Credentials`.
2. Найдите учетные данные, которые хотите изменить.
3. Нажмите кнопку `Edit`.
4. При необходимости обновите `Name`, `Access Token` и `Description`.
5. Нажмите кнопку `Save`.

## Удалить облачные учетные данные { #delete-cloud-credential }

1. Перейдите на страницу `Cloud Credentials`.
2. Найдите учетные данные, которые хотите удалить.
3. Нажмите кнопку с многоточием в столбце операций, затем выберите `Delete`.
4. Подтвердите удаление.
