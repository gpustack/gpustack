# Настройки сайта { #site-settings }

Администраторы платформы могут настроить оформление развёртывания GPUStack в разделе **Управление доступом → Настройки сайта**. Настройки общие для всех пользователей и организаций; они хранятся в базе данных сервера, сохраняются после перезапуска и доступны всем репликам.

## Настройка сайта { #customize-the-site }

1. Войдите как администратор платформы и откройте **Настройки сайта**.
2. Задайте название сайта и основной цвет.
3. При необходимости загрузите логотип, компактный логотип боковой панели, варианты для тёмной темы и значок сайта.
4. При необходимости задайте название компании и ссылку в подвале.
5. Нажмите **Сохранить изменения**. Текущий браузер применит настройки сразу, остальные — при следующей перезагрузке страницы.

Название сайта используется в заголовке браузера и альтернативном тексте логотипа. На странице входа оно отображается, если пользовательский логотип не задан. При отсутствии логотипа для тёмной темы используется соответствующее изображение для светлой темы. Очистка изображения восстанавливает встроенный ресурс; **Сбросить по умолчанию** восстанавливает основной цвет. Пустые поля подвала используют значения GPUStack по умолчанию.

Поддерживаются PNG, JPEG и WebP размером не более 512 KiB каждый. Изображения хранятся в базе данных; внешние URL изображений и загрузка SVG не поддерживаются. Ссылки в подвале могут быть HTTP(S) URL или путями того же источника, например `/about`.

Оформление доступно публично, в том числе до входа. Не включайте в эти поля конфиденциальные сведения.

Публичные ответы содержат ETag и требуют повторной проверки кэша. При совпадении `If-None-Match` сервер возвращает `304 Not Modified` без тела, избегая повторной загрузки неизменённых изображений. Каждый запрос всё ещё проверяет базу данных, чтобы сразу видеть изменения с другой реплики сервера.

## API { #api }

| Метод | Конечная точка | Доступ |
| --- | --- | --- |
| GET | `/v2/site-settings/public` | Только публичные поля оформления; без аутентификации |
| GET | `/v2/site-settings` | Администратор платформы |
| PUT | `/v2/site-settings` | Администратор платформы с областью доступа для управления |

`PUT` заменяет конфигурацию целиком. Обязательны `site_name` (1–128 символов) и `primary_color` (шестизначный шестнадцатеричный цвет, например `#007BFF`). Необязательные поля: `logo`, `logo_dark`, `mini_logo`, `mini_logo_dark`, `favicon`, `footer_name` (до 128 символов) и `footer_url` (до 2048 символов). Пропущенные необязательные поля очищаются. Изображения передаются как URL данных base64. Ответ включает `updated_at`, равный null до первого изменения содержимого. Неизвестные входные поля отклоняются.

## Совместимость развёртывания { #deployment-compatibility }

Для редактирования развёртывайте соответствующие версии сервера и UI вместе. Обновление Alembic создаёт таблицу `site_settings` в пакете миграций v2.3.1. До первого сохранения чтение возвращает значения GPUStack по умолчанию, не создавая запись. Откат версии удаляет таблицу и сохранённое оформление.

Если сервер старой версии или публичные настройки не загружены за пять секунд, UI запускается со значениями GPUStack по умолчанию. Ошибка чтения администраторских настроек отключает редактирование и позволяет повторить запрос.

Сборки с плагином оформления сохраняют его инициализацию и редактор. Встроенная страница настроек сайта доступна в сборках без такого плагина.
