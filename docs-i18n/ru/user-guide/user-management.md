# Управление пользователями { #user-management }

GPUStack имеет две роли пользователя: `Admin` и `User`.

Администраторы могут управлять кластерами, ресурсами, моделями, пользователями и настройками системы.

Пользователи могут управлять своими собственными ключами API и получать доступ к API модели.

## Администратор по умолчанию { #default-admin }

При начальной загрузке GPUStack создает пользователя-администратора по умолчанию.

Исходный пароль сохраняется в `<data-dir>/initial_admin_password`.

При настройке по умолчанию этот файл расположен по адресу `/var/lib/gpustack/initial_admin_password` внутри контейнера сервера.

Вы можете установить собственный пароль для администратора по умолчанию, используя флаг `--bootstrap-password` при запуске `GPUStack`.

## Требования к паролю { #password-requirements }

Пароль, установленный через пользовательский интерфейс или API, должен содержать хотя бы одну заглавную букву, одну строчную букву, одну цифру и один из следующих специальных символов:

```
! @ # $ % ^ & * _ + .
```

Пользовательский интерфейс дополнительно ограничивает длину паролей 6–64 символами.

## Создать пользователя { #create-user }

1. Перейдите на страницу `Users`.
2. Нажмите кнопку `Add User`.
3. Введите `Name`, `Full Name`, `Password` и выберите `Role` для пользователя.
4. Нажмите кнопку `Save`.

## Обновить пользователя { #update-user }

1. Перейдите на страницу `Users`.
2. Найдите пользователя, которого хотите редактировать.
3. Нажмите кнопку `Edit` в столбце `Operations`.
4. При необходимости обновите атрибуты.
5. Нажмите кнопку `Save`.

## Деактивировать пользователя { #deactivate-user }

1. Перейдите на страницу `Users`.
2. Найдите пользователя, которого хотите деактивировать.
3. Нажмите кнопку `Deactivate Account` в столбце `Operations`.

## Активировать пользователя { #activate-user }

1. Перейдите на страницу `Users`.
2. Найдите пользователя, которого хотите активировать.
3. Нажмите кнопку `Activate Account` в столбце `Operations`.

## Удалить пользователя { #delete-user }

1. Перейдите на страницу `Users`.
2. Найдите пользователя, которого хотите удалить.
3. Нажмите кнопку с многоточием в столбце `Operations`, затем выберите `Delete`.
4. Подтвердите удаление.

!!! note

    Пользователь-администратор не может быть деактивирован или удален из пользовательского интерфейса.
