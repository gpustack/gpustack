## Песочница чата { #chat-playground }

Работайте с API генерации ответов чата. Ниже показан пример интерфейса:

![Снимок экрана песочницы](../../assets/quick-start/quick-chat.png)

### Промпты { #prompts }

В левой части песочницы можно редактировать сообщения промпта. Доступны три роли: система, пользователь и ассистент.

- **Система**: обычно заранее заданная инструкция, которая устанавливает контекст, определяет поведение модели или ограничивает способ генерации ответов.
- **Пользователь**: входные данные или запрос человека, взаимодействующего с LLM.
- **Ассистент**: ответ, сгенерированный LLM.

#### Редактирование системного сообщения { #edit-system-message }

В верхней части песочницы можно добавить и отредактировать системное сообщение.

#### Редактирование сообщений пользователя и ассистента { #edit-user-and-assistant-messages }

Чтобы добавить сообщение пользователя или ассистента, нажмите `Add`.

Чтобы удалить сообщение пользователя или ассистента, нажмите кнопку с минусом в его правом углу.

Чтобы изменить роль сообщения, нажмите `User` или `Assistant` в его начале.

### Загрузка изображения { #upload-image }

Чтобы добавить изображения в промпт, нажмите `Upload Image`.

### Загрузка аудио { #upload-audio }

Чтобы добавить аудиофайлы в промпт, нажмите `Upload Audio`.

### Очистка промптов { #clear-prompts }

Нажмите `Clear`, чтобы очистить все промпты.

### Выбор модели { #select-model }

Выберите доступную модель GPUStack из раскрывающегося списка в правом верхнем углу песочницы. О развёртывании моделей см. [Управление развёртыванием моделей](../model-deployment-management.md).

### Настройка параметров { #customize-parameters }

В разделе `Parameters` можно настроить параметры генерации ответа.

### Генерация ответа { #do-completion }

Для генерации ответа нажмите `Submit` или клавишу Enter.

### Просмотр кода { #view-code }

Поэкспериментировав с промптами и параметрами, нажмите `View Code`, чтобы увидеть, как программно вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.

## Песочница сравнения { #compare-playground }

В песочнице можно сравнивать несколько моделей. Ниже показан пример интерфейса:

![Снимок экрана сравнения моделей](../../assets/playground/compare-playground.png)

### Режим сравнения { #comparison-mode }

Кнопками выбора вида можно включить сравнение 2, 3, 4 или 6 моделей.

### Промпты { #prompts_1 }

Сообщения промпта настраиваются так же, как в песочнице чата.

### Загрузка изображения { #upload-image_1 }

Чтобы добавить изображения в промпт, нажмите `Upload Image`.

### Загрузка аудио { #upload-audio_1 }

Чтобы добавить аудиофайлы в промпт, нажмите `Upload Audio`.

### Очистка промптов { #clear-prompts_1 }

Нажмите `Clear`, чтобы очистить все промпты.

### Выбор модели { #select-model_1 }

Выберите доступную модель GPUStack из раскрывающегося списка в левом верхнем углу каждой панели модели.

### Настройка параметров { #customize-parameters_1 }

Нажмите кнопку настроек соответствующей модели, чтобы изменить параметры генерации ответа.
