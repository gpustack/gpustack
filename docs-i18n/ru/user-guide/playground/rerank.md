# Песочница переранжирования { #rerank-playground }

Песочница переранжирования позволяет тестировать модели, которые упорядочивают несколько текстов по их релевантности запросу. Экспериментируйте с разными текстами, настраивайте параметры и изучайте примеры кода для интеграции с API.

## Добавление текста { #add-text }

Добавьте в документ несколько текстовых записей для переранжирования.

## Пакетный ввод текста { #batch-input-text }

Включите `Batch Input Mode`, чтобы разделить многострочный текст на записи по переводам строк. Это позволяет эффективно обрабатывать несколько фрагментов текста.

## Очистка { #clear }

Нажмите `Clear`, чтобы сбросить документ и результаты запроса.

## Запрос { #query }

Введите запрос и нажмите `Submit`, чтобы получить список текстов, упорядоченный по релевантности запросу.

![Переранжирование](../../assets/playground/reranker.png)

## Выбор модели { #select-model }

Выберите доступную модель переранжирования GPUStack из раскрывающегося списка моделей в правом верхнем углу песочницы.

## Настройка параметров { #customize-parameters }

В разделе параметров задайте `Top N` — количество подходящих текстов, которые нужно вернуть.

## Просмотр кода { #view-code }

Поэкспериментировав с текстом и запросом, нажмите `View Code`, чтобы увидеть, как вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.
