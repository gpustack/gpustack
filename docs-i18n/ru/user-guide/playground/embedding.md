# Песочница эмбеддингов { #embedding-playground }

Песочница эмбеддингов позволяет проверить преобразование текста в векторные представления. Можно экспериментировать с несколькими текстами, визуализировать эмбеддинги и изучать примеры кода для интеграции с API.

## Добавление текста { #add-text }

Добавьте не менее двух текстовых записей и нажмите `Submit`, чтобы получить эмбеддинги.

## Пакетный ввод текста { #batch-input-text }

Включите `Batch Input Mode`, чтобы автоматически разделить многострочный текст на записи по переводам строк. Это позволяет обрабатывать несколько фрагментов текста за одну операцию.

## Визуализация { #visualization }

Для визуализации эмбеддингов применяется метод главных компонент (PCA): он уменьшает размерность и отображает результаты на 2D-графике. Доступны два формата просмотра:

1. **График** — визуальное отображение результатов PCA.
2. **JSON** — исходные эмбеддинги в формате JSON.

Расстояние между точками на графике отражает сходство соответствующих текстов. Чем ближе точки, тем выше сходство.

## Очистка { #clear }

Нажмите `Clear`, чтобы сбросить введённые тексты и очистить результат.

## Выбор модели { #select-model }

Выберите доступную модель GPUStack из раскрывающегося списка моделей в правом верхнем углу песочницы.

## Просмотр кода { #view-code }

Поэкспериментировав с текстами, нажмите `View Code`, чтобы увидеть, как вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.
