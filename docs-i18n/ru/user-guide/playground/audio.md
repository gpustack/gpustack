# Песочница аудио { #audio-playground }

Песочница аудио предназначена для тестирования API преобразования текста в речь (TTS) и речи в текст (STT) в GPUStack. Она позволяет интерактивно преобразовывать текст в аудио и аудио в текст, настраивать параметры и изучать примеры кода для интеграции с API.

## Преобразование текста в речь { #text-to-speech }

Для тестирования моделей TTS откройте вкладку «Text to Speech».

### Ввод текста { #text-input }

Введите текст для преобразования, затем нажмите `Submit`, чтобы сгенерировать речь.

![Преобразование текста в речь](../../assets/playground/text-to-speech.png)

### Выбор модели { #select-model }

Выберите доступную модель TTS в GPUStack из раскрывающегося списка моделей в правом верхнем углу песочницы.

### Настройка параметров { #customize-parameters }

Настройте голос и формат выходного аудио.

!!! tip

    Набор поддерживаемых голосов зависит от модели.

### Просмотр кода { #view-code }

Поэкспериментировав с текстом и параметрами, нажмите `View Code`, чтобы увидеть, как вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.

## Преобразование речи в текст { #speech-to-text }

Для тестирования моделей STT откройте вкладку «Speech to Text».

### Передача аудиофайла { #provide-audio-file }

Передать аудио для распознавания можно двумя способами:

1. **Загрузить аудиофайл**
2. **Записать аудио в браузере**

!!! note

    Если запись в браузере недоступна, возможны следующие причины:

    1. При доступе через HTTPS или `http://localhost` браузеру необходимо разрешить использование микрофона.
    2. При доступе через `http://{host IP}` URL необходимо добавить в список доверенных адресов браузера.

          **Пример:**
          В Chrome откройте `chrome://flags/`, добавьте URL GPUStack в параметр «Insecure origins treated as secure» и включите его.

![Преобразование речи в текст](../../assets/playground/speech-to-text.png)

### Выбор модели { #select-model_1 }

Выберите доступную модель STT в GPUStack из раскрывающегося списка моделей в правом верхнем углу песочницы.

### Копирование текста { #copy-text }

Скопируйте результат распознавания речи, созданный моделью.

### Настройка параметров { #customize-parameters_1 }

Выберите язык аудиофайла, чтобы повысить точность распознавания.

### Просмотр кода { #view-code_1 }

Поэкспериментировав с аудиофайлами и параметрами, нажмите `View Code`, чтобы увидеть, как вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.
