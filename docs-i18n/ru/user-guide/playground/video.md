# Видео в Playground { #video-playground }

Видеоплощадка Playground позволяет тестировать API генерации видео GPUStack, настраивать параметры, воспроизводить результаты и просматривать примеры кода для интеграции с API.

## Генерация видео { #generate-video }

### Промпт { #prompt }

Введите промпт и нажмите **Отправить**, чтобы запустить асинхронную генерацию видео. Страница отслеживает только последнюю сохранённую задачу, а промпт остаётся в поле ввода для повторного использования. Если после ошибки проверки статуса отправить новый запрос, предыдущая задача может продолжить выполняться в движке инференса.

### Ход генерации { #generation-progress }

Пока страница видна, Playground проверяет статус текущей задачи каждые 5 секунд. Тайм-аут каждой проверки составляет 5 секунд. В области результата отображается состояние очереди или генерации. Если движок сообщает прогресс больше нуля, отображается процент выполнения. При ошибке или тайм-ауте проверки Playground скрывает состояние очереди или генерации и прекращает текущий опрос. Сообщение об ошибке появляется под областью результата, над полем промпта. После этого можно отправить новый запрос. Если проверка статуса возвращает HTTP 404, Playground также удаляет последнюю запись из браузера. При других ошибках запись сохраняется, и статус той же задачи можно проверить, обновив страницу или вернувшись на неё.

### Переход между страницами { #switch-pages }

Playground сохраняет в этом браузере ID последнего видео и отправленные параметры отдельно для каждой учётной записи. После обновления страницы он восстанавливает форму и запрашивает статус по этому ID. При уходе со страницы или скрытии вкладки опрос приостанавливается. При возвращении Playground снова проверяет сохранённую задачу.

### Текущая задача { #tasks }

В области результата видна текущая задача. Если при обновлении страницы задача уже завершена, плеер появляется после скачивания видео и определения его размеров. Доступность видео зависит от экземпляра, создавшего задачу, и срока её хранения в движке.

### Остановка запроса { #stop-request }

Нажатие кнопки **Отменить генерацию** на панели промпта сразу запускает отмену. Пока Playground ожидает ID видео, кнопка отменяет только запрос браузера на создание задачи. Если движок уже получил запрос, генерация может продолжиться. После получения ID Playground передаёт запрос на отмену движку инференса. После успешной отмены запись удаляется из браузера, а область результата снова становится пустой. Удалением файлов управляет движок.

Кнопка **Очистить запись о видео** рядом с кнопкой случайного промпта после подтверждения удаляет сохранённый ID видео, отправленные параметры и предпросмотр только из этого браузера.

## Выбор модели { #select-model }

Выберите доступную модель в раскрывающемся списке панели параметров. В списке отображаются только модели категории `video`. Если модели нет, убедитесь, что она запущена, а ее развертывание и маршрут используют правильную категорию.

Используйте совместимое развертывание SGLang Diffusion или vLLM-Omni. Модели понимания видео относятся к категории `llm` и используются в Chat Playground.

## Параметры { #parameters }

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `Duration (seconds)` | Значение модели или `4` | Если метаданные модели задают диапазон длительности, введите целое число в этом диапазоне, например от 4 до 15 секунд для MiniMax H3. Если диапазон не задан, доступны `4`, `8` и `12` секунд. Длительность готового видео может немного отличаться из-за выравнивания числа кадров. |
| `Resolution` | `832x480` или пресет модели | Размер результата в формате `widthxheight`. Пресет передает точные размеры. |
| `Seed` | Случайный | Снимите флажок **Случайный сид**, чтобы ввести фиксированное значение. |
| `Reference Image` | (пусто) | Необязательное изображение в расширенных настройках. Загрузите PNG/JPEG или укажите HTTP(S) URL изображения. |

Кнопка очистки удаляет выбранное изображение или URL. Поддержка референсного изображения зависит от модели. Выбор категории `video` не добавляет поддержку изображений модели, предназначенной только для генерации видео по тексту.

Выберите соотношение сторон плиткой, затем разрешение кнопкой. При наличии предлагаются 480p, 720p, 1080p и 4k, а точные ширина и высота показаны при наведении на вариант. Метаданные модели могут добавлять размеры или ограничивать их. Это пресеты интерфейса, а не гарантия поддержки движком. Пресета 21:9 нет; В разделе соотношения сторон `Custom` позволяет менять ширину и высоту ползунками или вводить числа. Начальный размер берется из метаданных модели, а при их отсутствии используется `832x480` (16:9) с учетом ограничений модели.

## Возможности модели { #model-capabilities }

Для MiniMax H3 метаданные модели указывают задачи, доступные для загруженного набора весов, разрешение по умолчанию и диапазон длительности 4–15 секунд. Если доступна задача `t2va`, Playground выбирает её по умолчанию. Сервер определяет возможности по файлам модели и загруженному набору весов как для Catalog, так и при прямом развёртывании из Hugging Face. Существующие развёртывания получают метаданные в ходе фоновой обработки.

При создании асинхронной задачи MiniMax H3 из Playground интерфейс преобразует параметры формы (`task`, `size`, `seconds` и референсные медиафайлы) в нативные параметры выбранного движка перед отправкой `POST /v1/videos`. SGLang использует `task`, `conditions` и `target`. vLLM-Omni использует `extra_params` и собственные поля референсов (`image_reference`, `video_reference`, `audio_reference`, `frame_indices`).

Поле `Duration (seconds)` в Playground принимает целое число секунд. Если движок поддерживает дробную длительность, её можно задать нативными параметрами в расширенных настройках.

Доступные типы задач определяются метаданными возможностей развёрнутой модели. Единственная доступная задача выбирается автоматически, а переключатель скрывается. Если задач несколько, выберите нужную в дополнительных настройках.

- `t2va`: элементы для референсов скрыты; запросы и примеры кода не содержат полей референсов.
- `fl2va`: загрузите изображение для первого кадра, последнего кадра или для обоих.
- `ref2va`: укажите одно изображение или видео через URL или загрузку. Для нескольких референсов или отдельного аудио используйте API.

Смена задачи или модели очищает референсы. Ограничения на файл: PNG/JPEG до 1 MiB, MP4/MOV до 2 MiB.

## Просмотр кода { #view-code }

Настроив промпт и параметры, нажмите `View Code`, чтобы увидеть вызов API с теми же входными данными. Доступны примеры для `curl`, `Python` и `Node.js`.

Примеры создают асинхронную задачу генерации видео, опрашивают ее состояние и загружают готовое видео. Описание конечных точек см. в разделе [Генерация видео](../../integrations/inference-apis.md#video-generation).
