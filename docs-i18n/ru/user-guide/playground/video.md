# Видео в Playground { #video-playground }

Видеоплощадка Playground позволяет тестировать API генерации видео GPUStack, настраивать параметры, воспроизводить результаты и просматривать примеры кода для интеграции с API.

## Генерация видео { #generate-video }

### Промпт { #prompt }

Введите промпт или воспользуйтесь кнопкой случайного промпта, затем нажмите `Submit`, чтобы создать видео.

### Ход генерации { #generation-progress }

Пока задача выполняется, поверх области видео отображаются анимация загрузки и сообщение о генерации (`Generating…`). Страница проверяет состояние задачи каждые 5 секунд. Процент показывается только тогда, когда движок инференса возвращает прогресс больше нуля. Некоторые движки не сообщают промежуточный прогресс.

Видео доступно для воспроизведения после завершения генерации и загрузки. Воспроизведение во время генерации не поддерживается.

### Переход между страницами { #switch-pages }

Пока отслеживается задача генерации, переход на другую страницу сохраняет форму и задачу. Проверки состояния приостанавливаются при уходе со страницы Video или переключении вкладки браузера в фоновый режим. При возвращении на активную страницу Video состояние той же задачи проверяется сразу, затем опрос возобновляется.

Это состояние хранится только в текущей странице браузера. Перезагрузка или закрытие страницы не сохраняет его.

### Остановка запроса { #stop-request }

Нажмите `Stop`, чтобы отменить текущий запрос браузера, прекратить проверки состояния и выйти из режима загрузки. Задача, уже принятая движком инференса, может продолжить выполнение: эта кнопка не отправляет движку запрос отмены. Повторная отправка создает новую задачу.

## Выбор модели { #select-model }

Выберите доступную модель в раскрывающемся списке в правом верхнем углу Playground. В списке отображаются только модели категории `video`. Если модели нет, убедитесь, что она запущена, а ее развертывание и маршрут используют правильную категорию.

Используйте совместимое развертывание SGLang Diffusion или vLLM-Omni. Модели понимания видео относятся к категории `llm` и используются в Chat Playground.

## Параметры { #parameters }

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `Duration` | `4` секунды | Запрашиваемая длительность видео. На странице доступны `4`, `8` и `12` секунд; допустимые значения зависят от модели и движка. |
| `Resolution` | `720x1280` | Размер результата в формате `widthxheight`. Доступные варианты и начальное значение могут изменяться в зависимости от метаданных модели. |
| `Reference Image` | (пусто) | Необязательное изображение в расширенных настройках. Загрузите PNG/JPEG или укажите HTTP(S) URL изображения. |

Кнопка очистки удаляет выбранное изображение или URL. Поддержка референсного изображения зависит от модели. Выбор категории `video` не добавляет поддержку изображений модели, предназначенной только для генерации видео по тексту.

## Просмотр кода { #view-code }

Настроив промпт и параметры, нажмите `View Code`, чтобы увидеть вызов API с теми же входными данными. Доступны примеры для `curl`, `Python` и `Node.js`.

Примеры создают асинхронную задачу генерации видео, опрашивают ее состояние и загружают готовое видео. Описание конечных точек см. в разделе [Генерация видео](../../integrations/inference-apis.md#video-generation).
