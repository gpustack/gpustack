# Песочница изображений { #image-playground }

Песочница изображений предназначена для тестирования API генерации изображений GPUStack. Можно интерактивно изучать возможности разных моделей, настраивать параметры и просматривать примеры кода для интеграции с API.

## Генерация изображения { #generate-image }

### Промпт { #prompt }

Введите промпт или сгенерируйте случайный, затем нажмите `Submit`, чтобы создать изображение.

![Изображение](../../assets/playground/create-image.png)

## Редактирование изображения { #edit-image }

Загрузите изображение и закрасьте области, которые хотите изменить. Затем введите промпт и нажмите `Submit`. Если ни одна область не закрашена, будет изменено всё изображение.

![Изображение](../../assets/playground/image-edit.png)

### Сохранение маски { #save-mask }

Нажмите `Save Mask`, чтобы сохранить закрашенные области отдельным изображением.

### Скачивание изображения { #download-image }

Нажмите `Download Image`, чтобы сохранить отредактированное изображение.

## Выбор модели { #select-model }

Выберите доступную модель GPUStack из раскрывающегося списка моделей в правом верхнем углу песочницы.

## Параметры { #parameters }

| Параметр | По умолчанию | Описание |
| ----------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Size` | `512x512` | Размер создаваемого изображения в формате 'ширинаxвысота'. |
| `Seed` | (пусто) | Начальное значение генератора случайных чисел. |

## Просмотр кода { #view-code }

Поэкспериментировав с промптами и параметрами, нажмите `View Code`, чтобы увидеть, как вызвать API с теми же входными данными. Доступны примеры на `curl`, `Python` и `Node.js`.
