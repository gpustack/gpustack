# Playground принятия решений { #decision-playground }

Playground принятия решений позволяет тестировать модели принятия решений, отвечающие типизированными вопросами на заданную ситуацию. Составьте state и questions, выполните их на развернутой модели и изучите типизированные ответы; доступны примеры кода для интеграции с API.

## State { #state }

Редактор `State` хранит ситуацию, относительно которой принимается решение — простой текст или JSON-объект/массив, например сообщения чата. Редактор проверяет JSON по мере ввода; state обязателен для запуска.

## Questions { #questions }

Редактор `Questions` хранит вопросы о state в виде JSON-объекта, сопоставляющего идентификатор вопроса с его определением. Кнопки `+ choice`, `+ score`, `+ noul` вставляют готовые к запуску шаблоны:

- `choice` — выбрать один вариант из `criteria` (имя варианта → описание).
- `score` — оценить state по упорядоченному списку уровней в `criteria`.
- `noul` — бинарный (да/нет) вопрос.

Редактор проверяет JSON и подсказывает схему, но набор вопросов остается открытым — специфичные для движка поля передаются как есть.

## Run { #run }

Выберите модель принятия решений, затем нажмите кнопку `Run` или `Ctrl`/`Cmd` + `Enter`, чтобы отправить state и questions на `/v1/systemone`. Кнопка `Stop` отменяет выполняющийся запрос.

![Playground принятия решений](../../assets/playground/decision.png)

## Answers { #answers }

Каждый ответ возвращается под своим идентификатором вопроса и отображается карточкой: вердикт (`Choice`, `Score` или тег да/нет для `noul`), `Confidence` и вероятности по вариантам. Строка сводки над карточками показывает, какая модель ответила, и расход токенов. Нераспознанные формы ответов отображаются в исходном JSON-виде.

## Выбор модели { #select-model }

Выберите доступную модель принятия решений, нажав выпадающий список моделей в правом верхнем углу интерфейса Playground. Перечисляются только модели категории `decision` — если модели нет в списке, убедитесь, что она запущена и категория задана верно; при необходимости измените категорию в настройках модели.

## Просмотр кода { #view-code }

Составив state и questions, нажмите кнопку `View Code`, чтобы увидеть, как вызвать API с тем же вводом. Примеры кода предоставляются на `curl`, `Python` и `Node.js`.
