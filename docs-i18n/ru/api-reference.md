# Справочник по API { #api-reference }

GPUStack предоставляет встроенный пользовательский интерфейс Swagger. Вы можете получить к нему доступ, перейдя к `<gpustack-server-url>/docs` в своем браузере, чтобы просмотреть API и взаимодействовать с ними.
