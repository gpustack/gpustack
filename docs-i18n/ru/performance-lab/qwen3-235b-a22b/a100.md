# Оптимизация пропускной способности Qwen3-235B-A22B на NVIDIA A100 GPU { #optimizing-qwen3-235b-a22b-throughput-on-nvidia-a100-gpus }


## Вывод { #conclusion }

![qwen3-235b-a22b-a100](../../assets/performance-lab/qwen3-235b-a22b-a100.png)

Рекомендуемая конфигурация для оптимизации пропускной способности Qwen3-235B-A22B-Instruct-2507 на A100 GPU:

???+ tip "Команда обслуживания модели"
    ```bash
    vllm serve Qwen/Qwen3-235B-A22B-Instruct-2507-FP8 -tp 4
    ```

Сравнение результатов бенчмарков до и после оптимизации:

| Сценарий бенчмарка | базовая конфигурация (vLLM без оптимизации) | После оптимизации |
|----------|-------------------------------------------|-----------|

| **Короткий запрос** | Общий TPS: 7449.43<br>Среднее TPOT(ms): 155.16 | Общий TPS: 4961.66x2 <span style="background-color:lightgreen;">(+33.2%)</span><br>Среднее TPOT(ms): 265.87 |
| **Запрос средней длины** | Общий TPS: 9342.67<br>Среднее TPOT(ms): 190.79 | Общий TPS: 5333.91x2 <span style="background-color:lightgreen;">(+14.2%)</span><br>Среднее TPOT(ms): 342.39 |
| **Длинный запрос** | Общий TPS: 8170.72<br>Среднее TPOT(ms): 205.64 | Общий TPS: 4633.41x2 <span style="background-color:lightgreen;">(+13.4%)</span><br>Среднее TPOT(ms): 347.13 |
| **Очень длинный запрос** | Общий TPS: 6657.49<br>Среднее TPOT(ms): 298.86 | Общий TPS: 4132.51x2 <span style="background-color:lightgreen;">(+24.1%)</span><br>Среднее TPOT(ms): 481.71 |


!!! note
    1. Наши бенчмарки не охватывают все возможные сочетания оптимизаций. Например, отправной точкой дальнейшей настройки становится движок инференса с лучшей производительностью при настройках по умолчанию. Такое отсечение вариантов даёт локальный оптимум, который может не совпадать с глобальным.
    2. Есть и другие методы оптимизации, зависящие от сценария использования: максимальный размер батча, настройки планировщика, расширенный KV-кэш, CUDA graph, Torch Compile и т. д. Выводы этого документа могут служить отправной точкой для более целенаправленной оптимизации.
    3. Тесты проводились на определённых аппаратных и программных конфигурациях. Развитие движков инференса может привести к новым выводам.
    4. Квантизация может влиять на точность, однако для большинства моделей FP8 обеспечивает снижение точности менее чем на 1%. Подробности см. в [результатах оценки](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark). Поэтому для обслуживания с высокой пропускной способностью настоятельно рекомендуется квантизация FP8.

Если что-то упущено или требуется обновление с учётом новых изменений, [сообщите нам](https://github.com/gpustack/gpustack/issues/new/choose).


## Цель оптимизации { #optimization-objective }

Высокая пропускная способность при высокой конкурентности запросов.

## Условия эксперимента { #experimental-setup }

### Модель { #model }

Qwen3-235B-A22B-Instruct-2507

### Оборудование { #hardware }

8 × NVIDIA A100 SXM 80GB GPU на одном узле.

### Версия движка { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.5.post1

### Набор данных бенчмарка { #benchmark-dataset }

1. ShareGPT
2. Случайный набор данных с различной длиной последовательностей:
    - Очень длинный запрос: 32000 входных токенов, 100 выходных токенов
    - Длинный запрос: 4000 входных токенов, 200 выходных токенов
    - Запрос средней длины: 2000 входных токенов, 100 выходных токенов
    - Короткий запрос: 128 входных токенов, 4 выходных токенов

### Скрипт бенчмарка { #benchmark-script }

Для оценки производительности модели используется **vLLM bench CLI**. Бенчмарк запускается следующей командой:

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-235B-A22B-Instruct-2507 --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
