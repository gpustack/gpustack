# Оценка ускорения prefill с LMCache в vLLM { #evaluating-lmcache-prefill-acceleration-in-vllm }

LMCache — расширяемый слой KV-кэша для инференса LLM, предназначенный для решения ключевых задач крупномасштабного развёртывания. В этом документе оценивается его влияние на производительность vLLM, прежде всего ускорение prefill и эффект при разных типах нагрузки.

## Выводы { #conclusions }

1. **LMCache существенно ускоряет prefill** при высокой доле попаданий в кэш: в экспериментах с многоходовыми диалогами с длинным контекстом (20K токенов) входной TPS вырос до +355.3%, а TTFT снизился на -58.8%.

2. **Преимущества производительности сильно зависят от нагрузки**:
   - **Оптимальные сценарии**: многоходовые диалоги с общими префиксами и повторяющимися шаблонами
   - **Менее подходящие сценарии**: случайные входы без повторного использования кэша

3. **Оптимизация размера блока**: в проверенных конфигурациях лучший результат показал размер блока по умолчанию 256.

4. **Промахи кэша создают накладные расходы**: без повторного использования кэша наблюдалось снижение производительности от -3% до -15%. Поэтому LMCache лучше всего подходит для нагрузок с предсказуемыми повторяющимися префиксами.

## Технические сведения { #technical-background }

### Обзор LMCache { #lmcache-overview }

LMCache расширяет возможности KV-кэша vLLM следующим образом:

| Компонент | Описание |
|-----------|-------------|
| Выгрузка на CPU | Расширяет ёмкость кэша за пределы VRAM GPU |
| Управление по блокам | Эффективное хранение и получение кэша с настраиваемым размером блоков |
| Несколько бэкендов | Поддержка локального хранилища, Redis и пользовательских бэкендов, например Mooncake |
| Распределённый KV-кэш | Общий кэш нескольких экземпляров vLLM |

### Основные сценарии использования { #key-use-cases }

1. **Низкая доля попаданий в кэш префиксов**: смягчает ограничения GPU VRAM и проблемы вытеснения кэша
2. **Распределённое совместное использование кэша**: позволяет нескольким экземплярам vLLM использовать общий кэш
3. **Разделение PD**: поддерживает архитектуры с раздельным развёртыванием prefill и decode

## Условия эксперимента { #experimental-setup }

- **Модель**: Qwen3-8B
- **Оборудование**: NVIDIA RTX 4090 24GB
- **Версия vLLM**: v0.10.1.1
- **Методика бенчмарка**: Бенчмарк многоходового диалога

??? info "Команды обслуживания модели"

    ```bash
    # Standard vLLM serving
    vllm serve Qwen/Qwen3-8B

    # LMCache-enabled serving
    ##### lmcache_config.yaml
    chunk_size: 256
    local_cpu: true
    max_local_cpu_size: 50
    #####
    LMCACHE_CONFIG_FILE=/root/lmcache_config.yaml vllm serve /root/Qwen3-8B \
    --kv-transfer-config '{"kv_connector":"LMCacheConnectorV1", "kv_role":"kv_both"}'
    ```
