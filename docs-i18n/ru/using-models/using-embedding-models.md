# Использование моделей эмбеддингов { #using-embedding-models }

**Эмбеддинги текста** — это числовые представления текста, отражающие его семантический смысл и позволяющие компьютеру определять связи и сходство между фрагментами текста. Они преобразуют текст в векторы в непрерывном пространстве, где близкие по смыслу тексты располагаются ближе друг к другу. Эмбеддинги широко применяются в обработке естественного языка, информационном поиске и рекомендательных системах.

В этом руководстве показано, как развертывать модели эмбеддингов в GPUStack и создавать векторные представления текста с помощью развернутых моделей.

## Предварительные условия { #prerequisites }

Прежде чем начать, убедитесь, что у вас есть следующее:

- GPUStack установлен и работает. Если нет, обратитесь к [Краткому руководству](../quickstart.md).
- Доступ к Hugging Face для загрузки файлов модели.

## Шаг 1. Развертывание модели { #step-1-deploy-the-model }

Выполните следующие шаги, чтобы развернуть модель из каталога:

1. Перейдите на страницу `Catalog` в пользовательском интерфейсе GPUStack.
2. На странице списка моделей используйте раскрывающийся список для фильтрации с помощью `Embedding`.
3. Просмотрите описание модели, максимальную длину контекста и поддерживаемые размеры.

![Развернуть модель](../assets/using-models/using-embedding-models/deploy-model.png)

После развертывания вы можете отслеживать состояние развертывания модели на странице `Deployments`.

![Список моделей](../assets/using-models/using-embedding-models/model-list.png)

## Шаг 2. Создайте ключ API. { #step-2-generate-an-api-key }

Для создания эмбеддингов текста будем использовать API GPUStack. Для этого нужен ключ API:

1. Перейдите на страницу `Access Control` > `API Keys`.
2. Нажмите кнопку `New API Key`.
3. Введите имя ключа API и нажмите кнопку `Save`.
4. Скопируйте сгенерированный ключ API. Вы можете просмотреть ключ API только один раз, поэтому обязательно сохраните его.

## Шаг 3. Создание эмбеддингов текста { #step-3-generate-text-embeddings }

После развертывания модели и получения ключа API можно создавать эмбеддинги текста через API GPUStack. Пример с использованием `curl`:

```bash
export SERVER_URL=<your-server-url>
export GPUSTACK_API_KEY=<your-api-key>
curl $SERVER_URL/v1/embeddings \
-H "Content-Type: application/json" \
-H "Authorization: Bearer ${GPUSTACK_API_KEY}" \
-d '{
  "model": "qwen3-embedding-4b",
  "input": "The food was delicious and the waiter...",
  "encoding_format": "float"
}'
```

Замените `<your-server-url>` URL-адресом вашего сервера GPUStack и `<your-api-key>` ключом API, который вы сгенерировали на предыдущем шаге.
