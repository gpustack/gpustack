# Использование больших языковых моделей { #using-large-language-models }

**Большие языковые модели (LLM)** — это мощные модели ИИ, способные понимать и генерировать текст, похожий на написанный человеком. Они применяются в чат-ботах, генерации контента, дополнении кода и других задачах.

В этом руководстве вы узнаете, как развертывать LLM в GPUStack и взаимодействовать с ними.

## Предварительные условия { #prerequisites }

Прежде чем начать, убедитесь, что у вас есть следующее:

- Компьютер Linux с одним или несколькими графическими процессорами и общим объемом видеопамяти не менее 30 ГБ. Мы будем использовать серверную часть vLLM, которая поддерживает только Linux.
- Доступ к [Hugging Face](https://huggingface.co/) или [ModelScope](https://www.modelscope.cn/) для загрузки файлов модели.
- GPUStack установлен и работает. Если нет, обратитесь к [Краткому руководству](../quickstart.md).

## Шаг 1. Развертывание больших языковых моделей { #step-1-deploy-large-language-models }

### Развертывание из каталога { #deploy-from-catalog }

Большие языковые модели в каталоге отмечены категорией `LLM`. Когда вы выбираете большую языковую модель из каталога, конфигурации по умолчанию должны работать, если у вас достаточно ресурсов графического процессора, а серверная часть совместима с вашей настройкой (например, для серверной части vLLM требуется рабочий процесс Linux amd64).

Здесь в качестве примера мы возьмем размещение `Qwen3 0.6B`.

Выполните следующие шаги, чтобы развернуть модель из каталога:

1. Перейдите на страницу `Catalog` в пользовательском интерфейсе GPUStack.
2. На странице списка моделей используйте раскрывающийся список для фильтрации с помощью `LLM`.
3. Просмотрите описание модели, максимальную длину контекста и поддерживаемые размеры.

![Список моделей](../assets/using-models/using-large-language-models/model-list.png)

#### Развертывание с использованием vLLM { #deployment-using-vllm }

1. Выберите `Qwen3 0.6B` из каталога.
2. При необходимости измените название модели и конфигурацию.
3. Нажмите кнопку `Save`, чтобы развернуть модель.

![Развернуть модель](../assets/using-models/using-large-language-models/deploy-model.png)

После развертывания вы можете отслеживать состояние развертывания модели на странице `Deployments` и ждать ее запуска.

## Шаг 2. Используйте LLM для генерации текста. { #step-2-use-the-llms-for-text-generation }

1. Перейдите на страницу `Playground` > `Chat` в пользовательском интерфейсе GPUStack.
2. Убедитесь, что развернутая модель выбрана в раскрывающемся списке `Model` в правом верхнем углу.
3. Предоставьте подсказку для создания текста.
4. Отрегулируйте `Parameters` справа в соответствии с вашими потребностями.
5. Нажмите кнопку `Submit`, чтобы сгенерировать текст.

Сгенерированная цепочка мыслей и результат будут отображаться в пользовательском интерфейсе.

![Сгенерировано](../assets/using-models/using-large-language-models/playground-chat.png)

Выполнив эти шаги, вы сможете использовать LLM для генерации текста с помощью искусственного интеллекта и задач на естественном языке в GPUStack. Поэкспериментируйте с различными подсказками и настройками, чтобы изучить все возможности LLM!
