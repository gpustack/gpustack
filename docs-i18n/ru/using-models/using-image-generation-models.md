# Использование моделей генерации изображений { #using-image-generation-models }

GPUStack поддерживает развертывание и запуск **Модели создания изображений**. В этом руководстве вы узнаете, как развернуть модель преобразования текста в изображение **Z-Image-Turbo** и создать изображения из текстовых подсказок в пользовательском интерфейсе GPUStack.

## Предварительные условия { #prerequisites }

Прежде чем начать, убедитесь, что у вас есть следующее:

- Графический процессор с объемом видеопамяти не менее 24 ГБ, например NVIDIA RTX 4090.
- GPUStack установлен и работает. Если нет, обратитесь к [Краткому руководству](../quickstart.md).
- Доступ к Hugging Face или ModelScope для загрузки файлов модели.

## Шаг 1. Развертывание модели Z-Image-Turbo. { #step-1-deploy-the-z-image-turbo-model }

Чтобы развернуть модель, выполните следующие действия:

1. Перейдите на страницу `Model Catalog` в пользовательском интерфейсе GPUStack.
2. Выберите `Image` в фильтре категорий.
3. Нажмите карточку модели `Z-Image-Turbo`, чтобы открыть страницу развертывания.
4. Сохраните настройки по умолчанию и нажмите кнопку `Save` для развертывания.

![Развернуть модель](../assets/using-models/using-image-generation-models/deploy-model.png)

После развертывания вы можете отслеживать статус на странице `Deployments`. После успешного развертывания щелкните значок многоточия на развертывании и выберите `Open in Playground`, чтобы начать использовать модель в Песочнице.

![Список моделей](../assets/using-models/using-image-generation-models/model-list.png)

## Шаг 2. Используйте модель для генерации изображения. { #step-2-use-the-model-for-image-generation }

В Песочнице `Image`:

1. Выберите раскрывающийся список `Size` и выберите желаемое разрешение изображения.
2. Введите приглашение с описанием изображения, которое вы хотите создать. Вы можете нажать кнопку `Random Prompt`, чтобы получить случайную подсказку для вдохновения.
3. Нажмите кнопку `Submit`, чтобы создать изображение.

Сгенерированное изображение будет отображаться в пользовательском интерфейсе. Результаты различаются в зависимости от случайности, начального числа и деталей подсказки.

![Сгенерировано](../assets/using-models/using-image-generation-models/image-playground.png)

## Заключение { #conclusion }

С помощью этой настройки вы можете создавать уникальные и визуально привлекательные изображения из текстовых подсказок, используя модель Z-Image-Turbo. Экспериментируйте с различными подсказками и настройками, чтобы создавать самые разнообразные изображения!
