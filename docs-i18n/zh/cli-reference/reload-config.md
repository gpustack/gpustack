# gpustack reload-config { #gpustack-reload-config }

重新加载可在运行时安全修改的配置值。

```bash
gpustack reload-config [OPTIONS]
```

## 配置 { #configurations }

| <div style="width:180px">参数</div> | <div style="width:100px">默认值</div> | 说明                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--set` value                       | (empty)                                | 使用 `key=value` 设置单个白名单字段（键采用连字符命名）。根据字段类型转换值：布尔值接受 `true/false`、`1/0`、`yes/no`、`y/n`、`on/off`；列表接受逗号分隔的字符串；字典要求 JSON 字符串。可多次指定 `--set`，后面的值覆盖前面的值，并覆盖 `--file` 中的值。 |
| `--file` value                      | (empty)                                | 从 YAML 文件加载配置。仅应用白名单字段，键统一转换为 snake_case。通过 `--set` 提供的值覆盖文件中的值。                                                                                                                                                                         |
| `--list`                            | `False`                                | 显示白名单字段及其值。指定此参数时，忽略其他选项。                                                                                                                                                                                                                                                                   |
| `--api-key` value                   | (empty)                                | 提供 API key，以管理员用户身份在 Server 端进行身份认证。                                                                                                                                                                                                                                                                            |
| `--server-port` value               | `30080`                                | 应用或列出运行时配置时使用的 GPUStack API Server 目标端口。省略时，优先使用已设置的 `GPUSTACK_API_PORT`，否则使用 `30080`。                                                                                                                                                                                        |
| `--worker-port` value               | `10150`                                | 应用或列出运行时配置时使用的 GPUStack Worker 目标端口。省略时，优先使用已设置的 `GPUSTACK_WORKER_PORT`，否则使用 `10150`。                                                                                                                                                                                         |
