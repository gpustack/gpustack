# NVIDIA H100 GPUs 上的 GLM-4.5-Air 吞吐量优化 { #optimizing-glm-45-air-throughput-on-nvidia-h100-gpus }


## 结论 { #conclusion }

![glm-4.5-air-h100](../../assets/performance-lab/glm-4.5-air-h100.png)

GLM-4.5-Air 在 H100 GPUs 上的吞吐量优化推荐配置：

???+ tip "推理服务命令"
    ```bash
    python3 -m sglang.launch_server --model zai-org/GLM-4.5-Air-FP8 \
    --tp-size 4 --ep-size 4 --tool-call-parser glm --reasoning-parser glm45
    ```

优化前后的基准测试结果对比：

| 基准测试用例 | 基准配置（未做任何优化的 vLLM） | 优化后（换算为相同 GPU 数量） |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | Total TPS: 7909.53<br>Mean TPOT(ms): 134.47 | Total TPS: 12411.25 <span style="background-color:lightgreen;">(+56.9%)</span><br>Mean TPOT(ms): 153.80 |
| **短提示词** | Total TPS: 7066.67<br>Mean TPOT(ms): 214.38 | Total TPS: 28621.61  <span style="background-color:lightgreen;">(+305.0%)</span><br>Mean TPOT(ms): 327.73 |
| **中等长度提示词** | Total TPS: 22582.76<br>Mean TPOT(ms): 125.44 | Total TPS: 35741.37  <span style="background-color:lightgreen;">(+58.3%)</span><br>Mean TPOT(ms): 106.94 |
| **长提示词** | Total TPS: 21705.53<br>Mean TPOT(ms): 82.53 | Total TPS: 33207.02 <span style="background-color:lightgreen;">(+53.0%)</span><br>Mean TPOT(ms): 71.49 |
| **超长提示词** | Total TPS: 20732.85<br>Mean TPOT(ms): 176.99 | Total TPS: 26683.88 <span style="background-color:lightgreen;">(+28.7%)</span><br>Mean TPOT(ms): 200.08 |


!!! note
    1. 基准测试未覆盖所有可能的优化组合。例如，我们会选择默认配置下表现最好的推理引擎作为后续调优的起点。这种剪枝方式得到的是局部最优解，未必是全局最优解。
    2. 其他优化方法取决于具体使用场景，包括最大批大小、调度配置、扩展 KV cache、CUDA graph 等。本文结论可作为进一步针对性优化的起点。
    3. 测试基于特定的硬件和软件环境。推理引擎的改进可能带来新的结论。
    4. 量化可能影响准确率，但对于大多数模型，FP8 量化的准确率下降可控制在 1% 以内。详情参见[评估结果](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark)。因此，强烈建议在高吞吐量推理服务场景中使用 FP8 量化。

如有遗漏或需要根据最新变化更新的内容，请[告诉我们](https://github.com/gpustack/gpustack/issues/new/choose)。

## 优化目标 { #optimization-objective }

在高并发请求场景下实现高吞吐量。

## 实验环境 { #experimental-setup }

### 模型 { #model }

zai-org/GLM-4.5-Air

### 硬件 { #hardware }

单节点配备 4 × NVIDIA H100 SXM GPU。

### 引擎版本 { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.4.post2
- TensorRT-LLM: v1.2.0rc1

### 基准测试数据集 { #benchmark-dataset }

1. ShareGPT
2. 不同序列长度的随机数据集：
    - 超长提示词：32000 输入 tokens，100 输出 tokens
    - 长提示词：4000 输入 tokens，200 输出 tokens
    - 中等长度提示词：2000 输入 tokens，100 输出 tokens
    - 短提示词：128 输入 tokens，4 输出 tokens

### 基准测试脚本 { #benchmark-script }

使用 **vLLM bench CLI** 工具对模型性能进行基准测试。运行基准测试的命令如下：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model zai-org/GLM-4.5-Air --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model zai-org/GLM-4.5-Air --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
