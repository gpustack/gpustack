# NVIDIA A100 GPUs 上的 Qwen3-32B 吞吐量优化 { #optimizing-qwen3-32b-throughput-on-nvidia-a100-gpus }


## 结论 { #conclusion }

![qwen3-32b-a100](../../assets/performance-lab/qwen3-32b-a100.png)

Qwen3-32B 在 A100 GPUs 上的吞吐量优化推荐配置：

???+ tip "推理服务命令"
    ```bash
    trtllm-serve Qwen/Qwen3-32B --max_seq_len=40960 --enable_chunked_prefill
    ```

优化前后的基准测试结果对比：

| 基准测试用例 | 基准配置（未做任何优化的 vLLM） | 优化后 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | Total TPS: 1730.98<br>Mean TPOT(ms): 149.67 | Total TPS: 2054.21 <span style="background-color:lightgreen;">(+18.7%)</span><br>Mean TPOT(ms): 89.01 |
| **短提示词** | Total TPS: 2656.71<br>Mean TPOT(ms): 528.57 | Total TPS: 3535.54 <span style="background-color:lightgreen;">(+33.1%)</span><br>Mean TPOT(ms): 1885.18 |
| **中等长度提示词** | Total TPS: 2521.38<br>Mean TPOT(ms): 143.23 | Total TPS: 2715.90 <span style="background-color:lightgreen;">(+7.7%)</span><br>Mean TPOT(ms): 145.49 |
| **长提示词** | Total TPS: 1837.08<br>Mean TPOT(ms): 96.19 | Total TPS: 2037.67 <span style="background-color:lightgreen;">(+10.9%)</span><br>Mean TPOT(ms): 100.09 |
| **超长提示词** | Total TPS: 1798.45<br>Mean TPOT(ms): 67.87 | Total TPS: 1580.36 <span style="background-color:#fbcaca;">(-13.8%)</span><br>Mean TPOT(ms): 47.37 |


!!! note
    1. 基准测试未覆盖所有可能的优化组合。例如，我们会选择默认配置下表现最好的推理引擎作为后续调优的起点。这种剪枝方式得到的是局部最优解，未必是全局最优解。
    2. 其他优化方法取决于具体使用场景，包括最大批大小、调度配置、扩展 KV cache、CUDA graph、Torch Compile 等。本文结论可作为进一步针对性优化的起点。
    3. 测试基于特定的硬件和软件环境。推理引擎的改进可能带来新的结论。

如有遗漏或需要根据最新变化更新的内容，请[告诉我们](https://github.com/gpustack/gpustack/issues/new/choose)。


## 优化目标 { #optimization-objective }

在高并发请求场景下实现高吞吐量。

## 实验环境 { #experimental-setup }

### 模型 { #model }

Qwen3-32B

### 硬件 { #hardware }

单个 NVIDIA A100 SXM 80GB GPU。

### 引擎版本 { #engine-version }

- vLLM: v0.11.0
- SGLang: v0.5.5.post1
- TensorRT-LLM: v1.2.0rc1

### 基准测试数据集 { #benchmark-dataset }

1. ShareGPT
2. 不同序列长度的随机数据集：
    - 超长提示词：32000 输入 tokens，100 输出 tokens
    - 长提示词：4000 输入 tokens，200 输出 tokens
    - 中等长度提示词：2000 输入 tokens，100 输出 tokens
    - 短提示词：128 输入 tokens，4 输出 tokens

### 基准测试脚本 { #benchmark-script }

使用 **vLLM bench CLI** 工具对模型性能进行基准测试。运行基准测试的命令如下：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-32B --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-32B --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
