# NVIDIA H100 GPUs 上的 GPT-OSS-120B 吞吐量优化 { #optimizing-gpt-oss-120b-throughput-on-nvidia-h100-gpus }

## 结论 { #conclusion }

![gpt-oss-120b-h100](../../assets/performance-lab/gpt-oss-120b-h100.png)

GPT-OSS-120B 在 H100 GPUs 上的吞吐量优化推荐配置：

???+ tip "推理服务命令"
    ```bash
    vllm serve openai/gpt-oss-120b --async-scheduling -tp 2
    ```

优化前后的基准测试结果对比：

| 基准测试用例 | 基准配置（未做任何优化的 vLLM） | 优化后 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | Total TPS: 6095.37<br>Mean TPOT(ms): 54.10 | Total TPS: 16042.19 <span style="background-color:lightgreen;">(+31.6%/GPU)</span><br>Mean TPOT(ms): 86.54 |
| **短提示词** | Total TPS: 17059.15<br>Mean TPOT(ms): 304.80 | Total TPS: 31517.47 <span style="background-color:#fbcaca;">(-7.6%/GPU)</span><br>Mean TPOT(ms): 183.05 |
| **中等长度提示词** | Total TPS: 14385.69<br>Mean TPOT(ms): 41.35 | Total TPS: 34083.02 <span style="background-color:lightgreen;">(+18.5%/GPU)</span><br>Mean TPOT(ms): 139.32 |
| **长提示词** | Total TPS: 14247.47<br>Mean TPOT(ms): 31.70 | Total TPS: 34491.13 <span style="background-color:lightgreen;">(+21.1%/GPU)</span><br>Mean TPOT(ms): 164.73 |
| **超长提示词** | Total TPS: 16136.57<br>Mean TPOT(ms): 23.99 | Total TPS: 32471.01 <span style="background-color:lightgreen;">(+0.6%/GPU)</span><br>Mean TPOT(ms): 220.32 |


!!! note
    1. 基准测试未覆盖所有可能的优化组合。例如，我们会选择默认配置下表现最好的推理引擎作为后续调优的起点。这种剪枝方式得到的是局部最优解，未必是全局最优解。
    2. 其他优化方法取决于具体使用场景，包括最大批大小、调度配置、扩展 KV cache、CUDA graph、Torch Compile 等。本文结论可作为进一步针对性优化的起点。
    3. 测试基于特定的硬件和软件环境。推理引擎的改进可能带来新的结论。

如有遗漏或需要根据最新变化更新的内容，请[告诉我们](https://github.com/gpustack/gpustack/issues/new/choose)。

## 优化目标 { #optimization-objective }

在高并发请求场景下实现高吞吐量。

## 实验环境 { #experimental-setup }

### 模型 { #model }

GPT-OSS-120B

### 硬件 { #hardware }

单节点配备 2 × NVIDIA H100 SXM GPU。

### 引擎版本 { #engine-version }

- vLLM: v0.10.2
- SGLang: v0.5.3rc0
- TensorRT-LLM: v1.0.0

### 基准测试数据集 { #benchmark-dataset }

1. ShareGPT
2. 不同序列长度的随机数据集：
    - 超长提示词：32000 输入 tokens，100 输出 tokens
    - 长提示词：4000 输入 tokens，200 输出 tokens
    - 中等长度提示词：2000 输入 tokens，100 输出 tokens
    - 短提示词：128 输入 tokens，4 输出 tokens

### 基准测试脚本 { #benchmark-script }

使用 **vLLM bench CLI** 工具对模型性能进行基准测试。运行基准测试的命令如下：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model openai/gpt-oss-120b --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model openai/gpt-oss-120b --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
