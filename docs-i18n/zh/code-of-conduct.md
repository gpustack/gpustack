# 贡献者行为准则 { #contributor-code-of-conduct }

## 我们的承诺 { #our-pledge }

作为社区成员、贡献者和负责人，我们承诺让每个人都能在不受骚扰的环境中参与社区，不论其年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育背景、社会经济地位、国籍、外貌、种族、种姓、肤色、宗教或性身份与性取向。

我们承诺以有助于建设开放、友善、多元、包容和健康社区的方式行事与交流。

## 我们的标准 { #our-standards }

有助于营造积极社区环境的行为包括：

- 对他人抱有同理心并友善相待
- 尊重不同的意见、观点和经历
- 提出建设性反馈，并以开放的态度接受反馈
- 为自己的错误承担责任，向受到影响的人道歉，并从中学习
- 关注整个社区的最佳利益，而不仅是个人利益

不可接受的行为包括：

- 使用带有性意味的语言或图像，以及任何形式的不受欢迎的性关注或示好
- 挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可，公布他人的住址、电子邮箱等私人信息
- 其他在专业环境中可以被合理认定为不当的行为

## 执行责任 { #enforcement-responsibilities }

社区负责人有责任明确并执行可接受行为的标准，对其认定为不当、威胁、冒犯或有害的行为，采取适当且公正的纠正措施。

社区负责人有权也有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、issue 及其他贡献，并在适当情况下说明管理决定的理由。

## 适用范围 { #scope }

本行为准则适用于所有社区空间，也适用于个人在公共空间正式代表社区的情况。
代表社区的情形包括使用官方电子邮箱、通过官方社交媒体账号发言，或作为指定代表参加线上或线下活动。

## 执行 { #enforcement }

如遇到辱骂、骚扰或其他不可接受的行为，可向负责执行本准则的社区负责人举报：
<contact@gpustack.ai>。
所有投诉均会得到及时、公正的审查和调查。

所有社区负责人都有义务尊重事件举报人的隐私和安全。

## 执行指南 { #enforcement-guidelines }

社区负责人将遵循以下社区影响指南，决定违反本行为准则的行为应承担的后果：

### 1. 纠正 { #1-correction }

**社区影响**：使用不当语言，或实施其他被认为不专业、在社区中不受欢迎的行为。

**后果**：社区负责人将私下发出书面警告，明确违规性质并解释行为不当的原因。可能要求公开道歉。

### 2. 警告 { #2-warning }

**社区影响**：通过单次事件或一系列行为违反本准则。

**后果**：发出警告，并说明继续违规的后果。在指定期限内，不得与相关人员互动，包括主动联系执行本行为准则的人员。此限制涵盖社区空间及社交媒体等外部渠道。违反这些条件可能导致临时或永久禁入。

### 3. 临时禁入 { #3-temporary-ban }

**社区影响**：严重违反社区标准，包括持续实施不当行为。

**后果**：在指定期限内，禁止与社区进行任何形式的互动或公开交流。在此期间，不得与相关人员进行公开或私下互动，包括主动联系执行本行为准则的人员。违反这些条件可能导致永久禁入。

### 4. 永久禁入 { #4-permanent-ban }

**社区影响**：反复违反社区标准，包括持续实施不当行为、骚扰个人，或攻击、贬低某类群体。

**后果**：永久禁止在社区内进行任何形式的公开互动。
