# 站点设置 { #site-settings }

平台管理员可以在 **访问控制 → 站点设置** 中自定义 GPUStack 部署的品牌信息。设置由所有用户和组织共享，保存在服务器数据库中，在重启后以及多个副本之间保持一致。

## 自定义站点 { #customize-the-site }

1. 以平台管理员身份登录并打开 **站点设置**。
2. 设置站点名称和主色。
3. 按需上传标志、侧栏小图标、深色主题版本和网站图标。
4. 按需设置页脚公司名称和链接。
5. 点击 **保存更改**。当前浏览器会立即应用设置，其他浏览器会在下次重新加载时使用新设置。

站点名称用于浏览器标题和标志的替代文本。未提供自定义标志时，登录页会显示自定义名称。深色主题标志缺失时使用对应的浅色主题图片。清除图片会恢复内置资源；**恢复默认** 会恢复默认主色。页脚字段为空时使用 GPUStack 默认值。

图片必须为 PNG、JPEG 或 WebP 格式，每张不超过 512 KiB。资源保存在数据库中，不支持外部图片 URL 或 SVG 上传。页脚链接支持 HTTP(S) URL 或 `/about` 等同源路径。

品牌信息公开可见，登录前也可读取。请勿在这些字段中包含机密信息。

公开读取响应包含 ETag，并要求缓存重新验证。匹配的 `If-None-Match` 请求会收到无响应体的 `304 Not Modified`，避免重复下载未更改的图片。每次读取仍会查询数据库，以立即获取其他服务器副本保存的更改。

## API { #api }

| 方法 | 端点 | 访问权限 |
| --- | --- | --- |
| GET | `/v2/site-settings/public` | 仅公开品牌字段，无需身份验证 |
| GET | `/v2/site-settings` | 平台管理员 |
| PUT | `/v2/site-settings` | 具有管理权限范围的平台管理员 |

`PUT` 替换整个配置。`site_name`（1–128 个字符）和 `primary_color`（六位十六进制颜色，例如 `#007BFF`）为必填项。可选字段为 `logo`、`logo_dark`、`mini_logo`、`mini_logo_dark`、`favicon`、`footer_name`（最多 128 个字符）和 `footer_url`（最多 2048 个字符）。省略的可选字段会被清除。图片值为 base64 数据 URL。响应包含 `updated_at`，其值在首次内容变更前为 null。未知输入字段会被拒绝。

## 部署兼容性 { #deployment-compatibility }

请配套部署对应的服务器和 UI 版本以启用编辑。服务器的 Alembic 升级会通过 v2.3.1 迁移包创建 `site_settings` 表。首次保存前，读取会返回 GPUStack 默认值，而不会创建记录。降级会删除该表及保存的品牌设置。

当 UI 连接旧版服务器，或无法在五秒内加载公开设置时，将使用 GPUStack 默认值启动。管理员设置读取失败时，编辑功能会禁用并提供重试入口。

带有品牌插件的构建会保留插件的品牌初始化流程和编辑器。内置站点设置页面仅在没有品牌插件的构建中提供。
