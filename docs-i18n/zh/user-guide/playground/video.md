# 视频 Playground { #video-playground }

视频 Playground 可用于测试 GPUStack 的视频生成 API，调整参数、播放生成结果，并查看 API 调用示例。

## 生成视频 { #generate-video }

### 提示词 { #prompt }

输入提示词，然后点击 **提交**，开始异步生成视频。页面只跟踪最近保存的一个任务，并在输入框中保留提示词，方便再次使用。状态查询报错后重新提交时，之前的任务可能仍在推理引擎上运行。

### 生成进度 { #generation-progress }

页面可见时，Playground 每 5 秒查询一次当前任务，每次最多等待 5 秒。结果区显示排队或生成状态。推理引擎返回大于 0 的生成进度时，页面显示百分比。状态查询报错或超时时，Playground 隐藏排队或生成状态并停止本轮轮询，在结果区下方、提示词输入框上方显示错误，此时可以重新提交。状态查询返回 HTTP 404 时还会清除当前浏览器中的最新记录。其他状态查询错误会保留记录，刷新或返回页面后可再次查询同一任务。

### 切换页面 { #switch-pages }

Playground 在当前浏览器中按账号保存最新的视频 ID 和已提交的参数。刷新后会恢复表单并查询该 ID。离开页面或隐藏标签页时暂停查询，返回后会重新查询已保存的任务。

### 当前任务 { #tasks }

结果区显示当前任务。刷新页面后，如果任务已完成，播放器会在视频下载完成且尺寸就绪后显示。视频能否访问取决于创建任务的推理实例和引擎保留任务的时间。

### 停止请求 { #stop-request }

点击提示词工具栏上的 **取消生成** 即可立即执行取消操作。等待视频 ID 时，此操作只取消浏览器的创建请求。如果推理引擎已收到请求，生成可能继续。取得 ID 后，Playground 会将取消请求转发给推理引擎。取消成功后会清除浏览器中的记录，结果区恢复为空状态。文件清理由推理引擎处理。

随机提示词按钮旁的 **清除视频记录** 会在确认后，仅清除当前浏览器中保存的视频 ID、已提交的参数和预览。

## 选择模型 { #select-model }

在参数面板的模型下拉框中选择可用模型。列表仅显示 `video` 类别的模型。如果模型没有出现，请确认模型正在运行，且部署和路由使用了正确的类别。

使用兼容的 SGLang Diffusion 或 vLLM-Omni 部署。视频理解模型使用 `llm` 类别，应在 Chat Playground 中测试。

## 参数 { #parameters }

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `时长 (秒)` | 模型默认值或 `4` | 模型有时长元数据时，可在指定范围内输入整数，例如 MiniMax H3 的 4–15 秒。没有时长元数据时，可选择 `4`、`8` 或 `12` 秒。成片时长可能因帧数对齐而略有差异。 |
| `分辨率` | `832x480` 或模型预设 | 按 `宽x高` 指定输出尺寸，选择预设后发送对应的实际宽高。 |
| `种子` | 随机 | 取消勾选 **随机种子** 后可输入固定种子。 |
| `参考图片` | （空） | 高级设置中的可选输入。上传 PNG/JPEG 图片，或填写 HTTP(S) 图片链接。 |

点击清除按钮可移除参考图片或链接。是否支持参考图片取决于所选模型；选择 `video` 类别不会让纯文生视频模型自动支持图片输入。

通过按钮选择比例，再选择分辨率档位；可用时提供 480p、720p、1080p 和 4k，悬停选项时显示实际宽高。模型 metadata 可补充尺寸或限制范围；这些是 UI 预设，不代表引擎一定接受全部尺寸。不提供 21:9 预设，在比例中选择 `Custom` 后，可通过滑块或数值输入调整宽高。初始尺寸优先采用模型 metadata 的预设，否则使用 `832x480`（16:9），并遵循模型尺寸限制。

## 模型能力 { #model-capabilities }

对于 MiniMax H3，模型元数据提供已加载权重分支支持的任务、默认分辨率以及 4–15 秒的时长范围。支持 `t2va` 时，Playground 默认选用该任务。服务端根据模型文件和加载的权重分支识别能力，支持 Catalog 部署和直接从 Hugging Face 部署。已有部署会通过后台协调补充能力元数据。

在 Playground 中创建 MiniMax H3 异步任务时，前端会在发送 `POST /v1/videos` 前，将表单中的 `task`、`size`、`seconds` 和参考素材转换为所选推理目标的原生参数：SGLang 使用 `task`、`conditions` 和 `target`，vLLM-Omni 使用 `extra_params` 和引擎专用参考字段（`image_reference`、`video_reference`、`audio_reference`、`frame_indices`）。

Playground 的 `时长 (秒)` 输入框接受整数秒。推理引擎支持时，可在高级参数中通过原生时长参数传入小数秒。

可用任务类型根据部署模型的能力 metadata 显示。只有一个可用任务时会自动选定并隐藏选择器；多个任务时可在高级配置中选择。

- `t2va`：隐藏参考素材控件，请求和代码示例均不包含参考素材字段。
- `fl2va`：上传图片作为首帧、尾帧，或同时上传两帧。
- `ref2va`：通过链接或上传文件提供一张参考图片或一段参考视频。多素材或独立音频组合可通过 API 使用。

切换任务或模型会清空参考素材。图片上传支持 PNG/JPEG，每个文件不超过 1 MiB；视频支持 MP4/MOV，不超过 2 MiB。

## 查看代码 { #view-code }

调整提示词和参数后，点击 `查看代码`，即可查看使用相同输入调用 API 的示例。支持 `curl`、`Python` 和 `Node.js`。

示例依次创建异步视频任务、轮询状态，并下载生成完成的视频。接口说明参见[视频生成](../../integrations/inference-apis.md#video-generation)。
