# 视频 Playground { #video-playground }

视频 Playground 可用于测试 GPUStack 的视频生成 API，调整参数、播放生成结果，并查看 API 调用示例。

## 生成视频 { #generate-video }

### 提示词 { #prompt }

输入提示词或点击随机提示词按钮，然后点击 `提交` 生成视频。

### 生成进度 { #generation-progress }

任务运行时，视频区域会显示加载动画和「生成中…」。页面每 5 秒查询一次任务状态。只有推理引擎返回大于 0 的进度时才显示百分比；部分引擎不会返回中间进度。

视频生成并下载完成后即可播放，当前不支持边生成边播放。

### 切换页面 { #switch-pages }

正在跟踪生成任务时，切换到其他页面会保留表单和任务。离开 Video 页面或将浏览器标签页切到后台后，状态查询会暂停；返回前台的 Video 页面时会立即查询同一个任务，并恢复轮询。

这些状态仅保存在当前浏览器页面中，刷新或关闭页面后不会保留。

### 停止请求 { #stop-request }

点击 `停止` 会取消当前浏览器请求、停止状态查询并结束加载状态。推理引擎已接受的生成任务仍可能继续执行：该按钮不会向引擎发送取消任务请求。再次提交会创建新任务。

## 选择模型 { #select-model }

在 Playground 右上方的模型下拉框中选择可用模型。列表仅显示 `video` 类别的模型。如果模型没有出现，请确认模型正在运行，且部署和路由使用了正确的类别。

使用兼容的 SGLang Diffusion 或 vLLM-Omni 部署。视频理解模型使用 `llm` 类别，应在 Chat Playground 中测试。

## 参数 { #parameters }

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `时长` | `4` 秒 | 请求生成的视频时长。页面提供 `4`、`8`、`12` 秒，实际接受的值取决于模型和推理引擎。 |
| `分辨率` | `720x1280` | 按 `宽x高` 指定输出尺寸。可选项和初始值可能随模型元数据变化。 |
| `参考图片` | （空） | 高级设置中的可选输入。上传 PNG/JPEG 图片，或填写 HTTP(S) 图片链接。 |

点击清除按钮可移除参考图片或链接。是否支持参考图片取决于所选模型；选择 `video` 类别不会让纯文生视频模型自动支持图片输入。

## 查看代码 { #view-code }

调整提示词和参数后，点击 `查看代码`，即可查看使用相同输入调用 API 的示例。支持 `curl`、`Python` 和 `Node.js`。

示例依次创建异步视频任务、轮询状态，并下载生成完成的视频。接口说明参见[视频生成](../../integrations/inference-apis.md#video-generation)。
