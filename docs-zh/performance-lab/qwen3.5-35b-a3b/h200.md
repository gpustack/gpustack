# Qwen3.5-35B-A3B 吞吐量优化 { #optimizing-qwen35-35b-a3b-throughput }

## 结论 { #conclusion }

![吞吐量优化结果](../../assets/performance-lab/qwen3.5-35b-a3b-h200.png)

Qwen3.5-35B-A3B 在 NVIDIA H200 上的吞吐量优化推荐配置：

???+ tip "推理服务命令"
    ```bash
    vllm serve Qwen/Qwen3.5-35B-A3B-FP8 \
        --reasoning-parser=qwen3 \
        --performance-mode=throughput \
        --max-model-len=32768 \
        --enable-prefix-caching
    ```


优化前后的基准测试结果对比：

| 基准测试用例 | 基准配置（未做任何优化的 vLLM） | 优化后 |
|----------|-------------------------------------------|-----------|
| **ShareGPT 测试配置** | Total TPS: 9632.01<br>Mean TPOT(ms): 25.89 | Total TPS: 10570.88 <span style="background-color:lightgreen;">(+9.75%)</span><br>Mean TPOT(ms): 24.71 |
| **吞吐量测试配置** | Total TPS: 37934.72<br>Mean TPOT(ms): 45.39 | Total TPS: 50464.84 <span style="background-color:lightgreen;">(+33.03%)</span><br>Mean TPOT(ms): 41.12 |
| **长上下文测试配置** | Total TPS: 44993.20<br>Mean TPOT(ms): 319.79 | Total TPS: 56424.42 <span style="background-color:lightgreen;">(+25.41%)</span><br>Mean TPOT(ms): 227.43 |
| **生成密集型测试配置** | Total TPS: 10455.38<br>Mean TPOT(ms): 2.48 | Total TPS: 12258.79 <span style="background-color:lightgreen;">(+17.25%)</span><br>Mean TPOT(ms): 2.92 |


!!! note
    1. 基准测试未覆盖所有可能的优化组合。例如，我们会选择默认配置下表现最好的推理引擎作为后续调优的起点。这种剪枝方式得到的是局部最优解，未必是全局最优解。
    2. 其他优化方法取决于具体使用场景，包括最大批大小、调度配置、扩展 KV cache、CUDA graph 等。本文结论可作为进一步针对性优化的起点。
    3. 测试基于特定的硬件和软件环境。推理引擎的改进可能带来新的结论。
    4. 量化可能影响准确率，但对于大多数模型，FP8 量化的准确率下降可控制在 1% 以内。详情参见[评估结果](https://github.com/Tencent/AngelSlim/blob/main/README_en.md#-benchmark)。因此，强烈建议在低延迟推理服务场景中使用 FP8 量化。
    5. 推测解码能够显著降低低并发请求的延迟，但加速效果取决于基准测试数据集的数据分布和草稿模型的选择。例如，本测试所选的草稿模型使用英文数据训练，在其他语言上的表现可能不够理想。

如有遗漏或需要根据最新变化更新的内容，请[告诉我们](https://github.com/gpustack/gpustack/issues/new/choose)。

### 基准测试方法 { #benchmark-method }

本项目使用 GPUStack 的一键基准测试功能评估推理服务工作负载。本文中的基准测试均通过该流程执行。

GPUStack 的基准测试通过封装项目 [benchmark-runner](https://github.com/gpustack/benchmark-runner)，基于 [guidellm](https://github.com/vllm-project/guidellm) 实现。

对于以下基准测试配置，GPUStack 负责模型部署、基准测试任务提交和结果收集。

### 开源工具替代方案 { #open-source-replacement }

如果不使用 GPUStack，可以直接执行 `guidellm benchmark` 命令替代 GPUStack 基准测试流程。

对于包含 `dataset_name: ShareGPT` 的测试配置：

```bash
guidellm benchmark \
  --target ${target} \
  --profile constant \
  --rate ${request_rate} \
  --max-requests ${total_requests} \
  --processor ${model_path} \
  --data ./ShareGPT_V3_unfiltered_cleaned_split.json
```

对于包含 `dataset_name: Random` 的测试配置：

```bash
guidellm benchmark \
  --target ${target} \
  --profile constant \
  --rate ${request_rate} \
  --max-requests ${total_requests} \
  --processor ${model_path} \
  --data "prompt_tokens=${dataset_input_tokens},output_tokens=${dataset_output_tokens}" \
  --random-seed ${dataset_seed:-42}
```
