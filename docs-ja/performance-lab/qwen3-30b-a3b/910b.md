# ASCEND 910B NPU 上での Qwen3-30B-A3B のスループット最適化 { #optimizing-qwen3-30b-a3b-throughput-on-ascend-910b-npus }

## 結論 { #conclusion }

![qwen3-30b-a3b-910b](../../assets/performance-lab/qwen3-30b-a3b-910b.png)

ASCEND 910B NPU 上で Qwen3-30B-A3B のスループットを最適化するための推奨設定：

???+ tip "推論サービスのコマンド"
    ```bash
    # This is a simplified vLLM-like command. GPUStack maps arguments to the
    # corresponding MindIE JSON configuration and runs with mindieservice_daemon.
    mindie serve Qwen/Qwen3-30B-A3B
    ```

最適化前後のベンチマーク結果の比較：

| ベンチマークケース | 基準設定（最適化なしの vLLM） | 最適化後 |
|----------|-------------------------------------------|-----------|
| **ShareGPT** | 合計 TPS: 1227.19<br>平均 TPOT(ms): 318.03 | 合計 TPS: 4712.47 <span style="background-color:lightgreen;">(+284.0%)</span><br>平均 TPOT(ms): 964.45 |
| **短いプロンプト** | 合計 TPS: 5340.68<br>平均 TPOT(ms): 312.49 | 合計 TPS: 15040.15 <span style="background-color:lightgreen;">(+181.6%)</span><br>平均 TPOT(ms): 1249.72 |
| **中程度のプロンプト** | 合計 TPS: 7843.85<br>平均 TPOT(ms): 344.86 | 合計 TPS: 15591.71 <span style="background-color:lightgreen;">(+98.8%)</span><br>平均 TPOT(ms): 194.54 |
| **長いプロンプト** | 合計 TPS: 5881.36<br>平均 TPOT(ms): 277.5 | 合計 TPS: 13362.49 <span style="background-color:lightgreen;">(+127.2%)</span><br>平均 TPOT(ms): 130.97 |
| **非常に長いプロンプト** | 合計 TPS: 3704.57<br>平均 TPOT(ms): 503.84 | 合計 TPS: 10830.52 <span style="background-color:lightgreen;">(+192.4%)</span><br>平均 TPOT(ms): 242.08 |


!!! note
    1. 本ベンチマークは、考えられるすべての最適化の組み合わせを網羅していません。たとえば、デフォルト設定で最も性能が高い推論エンジンを選び、それを追加調整の出発点としています。このような候補の絞り込みで得られるのは局所最適解であり、大域最適解とは限りません。
    2. 最大バッチサイズ、スケジューリング設定、拡張 KV キャッシュ、CUDA graph、Torch Compile など、利用シナリオに応じた最適化もあります。本書の結論は、用途に合わせてさらに最適化するための出発点として利用できます。
    3. 本テストは特定のハードウェアとソフトウェアの構成で実施しています。推論エンジンの進化により、結論が変わる可能性があります。

記載漏れや最新の変更を反映すべき点があれば、[お知らせください](https://github.com/gpustack/gpustack/issues/new/choose)。

## 最適化の目標 { #optimization-objective }

高並列度のリクエストで高スループットを実現します。

## 実験環境 { #experimental-setup }

### モデル { #model }

Qwen/Qwen3-30B-A3B

### ハードウェア { #hardware }

単一の Ascend 910B NPU。

### エンジンのバージョン { #engine-version }

- vLLM-Ascend: v0.9.1
- MindIE: 2.1RC1

### ベンチマークデータセット { #benchmark-dataset }

1. ShareGPT
2. シーケンス長を変えたランダムデータセット：
    - 非常に長いプロンプト： 32000 入力トークン, 100 出力トークン
    - 長いプロンプト： 4000 入力トークン, 200 出力トークン
    - 中程度のプロンプト： 2000 入力トークン, 100 出力トークン
    - 短いプロンプト： 128 入力トークン, 4 出力トークン

### ベンチマークスクリプト { #benchmark-script }

モデルの性能評価には **vLLM bench CLI** ツールを使用します。ベンチマークを実行するコマンドは次のとおりです：

```bash
# Prepare the ShareGPT dataset
wget https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered/resolve/main/ShareGPT_V3_unfiltered_cleaned_split.json

# Benchmark on ShareGPT dataset
vllm bench serve --model Qwen/Qwen3-30B-A3B --backend openai-chat --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000

# Benchmark on random dataset (fixed seed for reproducibility)
vllm bench serve --model Qwen/Qwen3-30B-A3B --backend openai-chat --endpoint /v1/chat/completions --dataset-name random --random-input-len 4000 --random-output-len 200 --num-prompts 500 --seed 42
```
